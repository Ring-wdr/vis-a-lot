그린 차트는 툴팁으로 값을 읽고, 탭 도구 줄의 **모드 바**로 확대·선택·도형 같은 조작을 합니다. 조작은 item마다 따로 적용되고, 조작한 item만 서버가 다시 그립니다.

## 툴팁

item 위에 커서를 올리면 툴팁이 뜹니다. 처음 커서를 올릴 때만 잠깐 기다리고, 그다음부터는 바로 뜹니다.

| 차트 | 툴팁 내용 |
| --- | --- |
| Scatter · Line | 커서 위치의 x·y 값과 가장 가까운 점 |
| Bar · Pie · Treemap 등 | 가리킨 막대·조각의 값 |
| Boxplot | 사분위수 같은 통계값 |
| Histogram | 구간 범위와 개수 |
| Candle | 구간·시가·고가·저가·종가·개수 |
| Gantt | 행·legend 값·시작·끝·길이 |

왼쪽 패널 **tooltip**에서 고른 컬럼은 가장 가까운 점(행)의 값으로 함께 보입니다. scatter·line의 가까운 점 표시는 전체 설정의 툴팁 메뉴에서 끌 수 있습니다.

## 모드 바

모드는 하나만 켤 수 있습니다. 차트를 그리기 전이나 history에서 다시 볼 때는 **기본** 모드만 쓸 수 있습니다.

| 모드 | 하는 일 |
| --- | --- |
| 기본 | 툴팁을 봅니다 |
| 이동 | 차트를 끌어 보는 범위를 옮깁니다. 놓으면 옮긴 범위로 다시 그립니다 |
| 확대 | 끌어서 고른 영역으로 확대합니다 |
| 사각형 선택 · 자유형 선택 | 끌어서 영역을 고릅니다. 영역 밖은 흐리게 그리고, 제목 줄에 선택한 수를 적습니다 |
| 사각형 삭제 · 자유형 삭제 | 고른 영역의 점을 그 item에서 뺍니다 (scatter·line) |
| 페인트 | 차트 위에 도형과 메모를 그립니다 |

차트마다 쓸 수 있는 모드는 [차트 종류](/help/vis/chart-types#차트마다-쓸-수-있는-도구)에 정리했습니다.

### 확대와 축소

확대 모드에서 영역을 끌어 고르면 그 범위로 다시 그립니다. 시계열 축도 아주 좁은 범위까지 확대할 수 있습니다. item 오른쪽 위 도구의 **축소**는 정해진 비율만큼 줄이고, **확대 초기화**는 처음 범위로 돌아갑니다.

### 영역 선택

선택 모드에서 끌지 않고 클릭하면 선택을 풉니다. item마다 선택 영역은 하나입니다. 선택한 영역에서 우클릭하면 메뉴가 열립니다.

| 메뉴 | 하는 일 |
| --- | --- |
| 즐겨찾기에 추가… | 지금 영역에 이름을 붙여 남깁니다 |
| 새 범례… | 영역 안의 점을 새 legend 항목으로 칠합니다 (8개까지) |
| 선택 해제 | 선택을 풉니다 |
| 즐겨찾기 선택 ▸ | 남긴 영역을 다시 고릅니다 |
| 즐겨찾기 삭제 ▸ | 남긴 영역을 지웁니다 |
| 지운 점 모두 되돌리기 | 점 삭제로 뺀 점을 모두 되돌립니다 |
| 새 범례 삭제 ▸ | 만든 legend 항목을 지웁니다 |

선택 영역이 있으면 데이터 테이블과 데이터 다운로드가 그 안의 행만 담습니다(scatter·line·bar·boxplot·histogram·waterfall).

### 점 삭제

사각형 삭제·자유형 삭제 모드에서 고른 영역의 점을 그 item에서 뺍니다. 원본 데이터는 그대로이고, 그림·점 수·툴팁에서만 빠집니다. item 도구의 **지운 점 되돌리기**는 마지막 영역을, 우클릭 메뉴의 **지운 점 모두 되돌리기**는 전부 되돌립니다.

### 페인트

페인트 모드에서는 item 왼쪽 위에 그리기 도구가 뜹니다.

- **사각형 · 선 · 자유곡선 · 텍스트** 중 고릅니다. 탭 안의 모든 item이 같은 도구를 씁니다.
- 마우스를 떼면 저장하고 그 item을 다시 그립니다. 도형은 데이터 좌표로 저장되므로 확대해도 같은 자리에 붙어 있습니다.
- 그린 도형은 고칠 수 없습니다. **도형 되돌리기**(마지막 도형 지우기)와 **도형 전체 삭제**만 있습니다.

## item 도구

item 위에 커서를 올리면 오른쪽 위에 도구가 나타납니다.

- **축소**, **확대 초기화**
- **지운 점 되돌리기** (점을 지웠을 때)
- **item 속성**: 이 item에만 적용할 속성(legend 위치·색 등)을 바꿉니다. → [꾸미기](/help/vis/customize#item-개별-속성)
- **크게 보기**

## 크게 보기

item을 더블 클릭하거나 **크게 보기**를 누르면 grid 자리에 그 item 하나를 크게 보여 줍니다. 크게 본 item에서도 툴팁·확대·도형·색 조작이 똑같이 됩니다.

- 아래 섬네일 줄에서 다른 item을 고릅니다.
- <Kbd>←</Kbd> <Kbd>→</Kbd>: 이전·다음 item, <Kbd>Home</Kbd> <Kbd>End</Kbd>: 처음·마지막 item
- 다시 더블 클릭하거나 <Kbd>Esc</Kbd>, **grid로 돌아가기**를 누르면 그 item이 있는 페이지로 돌아갑니다.

## item 고르기

item을 누르면 테두리가 강조되며 그 item을 고른 상태가 됩니다. 차트 다운로드·데이터 다운로드·데이터 테이블처럼 item 하나에 쓰는 도구는 item을 고른 뒤에 쓸 수 있습니다. 새로 draw하면 고른 item이 풀립니다.
