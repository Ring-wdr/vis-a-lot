チャートを描くには、まずデータを登録する必要があります。左パネルの **データ** で選べるのは登録済みのデータだけです。

## サンプルデータを登録する

製造/IoT センサーデータをサンプルとして用意しています。行数によって 10 万・50 万・100 万行の 3 種類があります。

1. トップバーから **datastore** を開きます。
2. 一覧の一番下にあるサンプルのいずれかで **登録** を押します。
3. 状態が **準備完了** になると使えます。一度作成したデータはブラウザに残るため、次回は作り直しません。

サンプルデータのカラムは次のとおりです。

| カラム | 型 | 説明 |
| --- | --- | --- |
| 測定時刻 (`ts`) | 日時 | 30 日間の測定時刻 |
| 工場 (`factory`) | カテゴリ | 3 個 |
| ライン (`line`) | カテゴリ | 工場ごとに 4 個 |
| 設備 (`machine`) | カテゴリ | 約 120 個 |
| センサー種類 (`sensor_type`) | カテゴリ | 温度・振動・圧力・電流 |
| シフト (`shift`) | カテゴリ | 日勤・夜勤・深夜 |
| LOT (`lot_id`) | カテゴリ | 約 5,000 個 |
| 状態 (`status`) | カテゴリ | 正常・警告・異常 |
| 測定値 (`value`) | 数値 | 1 日周期の変動、設備ごとのドリフト、異常区間が混ざった値 |
| 周囲温度 (`temperature_env`) | 数値 | 測定値と相関があります |
| 負荷率(%) (`load_pct`) | 数値 | 設備の負荷率 |

## 自分のファイルをアップロードする

トップバーの **upload**(またはスタート画面の「データをアップロード」)から、CSV ファイル 1 つ、または CSV をまとめた zip をアップロードします。

1. **ファイルを選択** でファイルを選びます。zip の場合は、左側に中の CSV の一覧が表示されます。
2. 右側の **前処理オプション** を調整します。オプションを変えると、少し後に下のプレビューが更新されます。
3. プレビュー表のヘッダーで、取り込むカラム(チェック)と型を決めます。
4. 必要に応じて **検査** でファイル全体を事前に確認します。
5. **OK** を押すと読み込みが始まり、下の行に進行状況が表示されます。終わると datastore のポップアップに移ります。

### 前処理オプション

| オプション | 内容 |
| --- | --- |
| 区切り文字 | カンマ・タブ・セミコロン・縦棒、または任意の 1 文字を直接入力 |
| 1 行目をヘッダーにする | オフにするとカラム名が `column_1`、`column_2`… になります |
| Null 値 | この値と同じセルを空の値(null)として読みます。既定は空のセルです |
| 引用符 | 値を囲む引用符 1 文字。既定は `"` です |
| 日時の形式 | `自動 (ISO 8601)` または `yyyy-MM-dd HH:mm:ss` のようなパターン。この形式で読めるカラムを日時として扱います |
| データエラーを無視 | オンにすると、型に合わない値は null として取り込み、セル数が合わない行はスキップします。オフにすると、そのような値があるときは理由とともに拒否します |
| エンコーディング | 自動(UTF-8、文字化けする場合は EUC-KR)、UTF-8、EUC-KR |

### カラムの型

型は値を見て自動的に決まります。すべて数値なら **数値**、すべて日時の形式で読めれば **日時**、それ以外は **カテゴリ** です。プレビュー表のヘッダー 2 行目でカラムごとに変更でき、選んだ型に変換できないセルは赤く表示されます。

カラムの型によって、チャートでそのカラムをどこに使えるかが決まります。たとえば bar の x にはカテゴリのカラムだけ、y には数値のカラムだけを選べます。→ [チャートの種類](/help/vis/chart-types)

### 検査

**検査** は読み込まずにファイル全体を読み、行数と、カラムごとに変換できない値の数を知らせます。大きなファイルは読み込む前に検査しておくことをおすすめします。

### zip ファイル

zip 内の CSV(サブフォルダーを含む)は、名前順に **1 つのデータにまとめます**。CSV 以外のファイルはスキップします。CSV 同士でカラムの数・名前・型が 1 つでも異なると全体を拒否し、どのファイルのどのカラムが異なるかを知らせます。

<Callout tone="warn" title="上限">
  展開後のサイズ 300MB、CSV 500 個、カラム 200 個までアップロードできます。
</Callout>

## datastore

登録済みデータの一覧です。アップロードしたデータが上(新しい順)、サンプルが一番下にあります。

- 名前で検索します。
- データを選んで **gallery で開く**(またはダブルクリック)を押すと、そのデータで新しい gallery タブが開きます。
- **編集**: 同じアップロードのポップアップが編集モードで開きます。名前・オプション・型・取り込むカラムを変えて **再読み込み** します。元のファイルは変更できず、再読み込みが拒否された場合は既存のデータをそのまま残します。
- **削除**: アップロードしたデータを削除します。サンプルは編集・削除できず、読み込み中のデータも削除できません。
- 下部にブラウザのストレージ使用量が表示されます。
