描いたチャートは、画像・Excel・CSV でダウンロードしたり、リンクで共有したり、データ共有フィードに投稿したりできます。

## チャートツール

タブツールバー中央のチャートツールです。item 1 つに使うツールは、先に item を押して選ぶ必要があります。

| ツール | できること | item の選択 |
| --- | --- | --- |
| チェックボックス表示 | legend 項目にチェックボックスを表示して値を隠します → [装飾](/help/vis/customize#ja-チェックボックスで値を隠す) | |
| チャートをダウンロード | 選んだ item を `名前.png` として保存します | 必要 |
| すべてのチャートを Excel でダウンロード | すべての item の PNG を 1 つの xlsx ファイルにまとめます | |
| データをダウンロード | 選んだ item の行を CSV で保存します | 必要 |
| データテーブル | 選んだ item の行を表で見ます | 必要 |
| 全データテーブル | データ全体を表で見ます(最大 30,000 行のサンプル) | |

### すべてのチャートを Excel でダウンロード

「チャート」シートに grid と同じ列数で item 名と画像を配置し、「一覧」シートに番号・名前・状態を記します。ファイルサイズのため、先頭から **300 個** までしか画像を入れません。描けなかった item は一覧にだけ残ります。

### データテーブルとデータのダウンロード

選んだ item に使われた元の行を、データのすべてのカラムで表示します。

- split の組み合わせ、draw したときに適用したフィルター、チェックボックスで隠した legend の値が反映されます。
- 選択領域がある場合はその中の行だけを、点を削除した場合は削除した行を除いた残りを含めます(scatter・line・bar・boxplot・histogram・waterfall)。
- 列見出しを押すと、昇順 → 降順 → 並べ替えなしの順に切り替わります。
- データのダウンロードでは、同じ行を Excel ですぐに開ける CSV で保存します。選択領域がある場合は、ファイル名に `_選択` が付きます。

### 全データテーブル

draw したときに適用したフィルターで絞り込んだデータ全体を表示します。行が 30,000 を超える場合は 30,000 行だけを無作為に抽出して表示し、表のヘッダーに「全 N 行中 30,000 行のサンプル」と記します。ページを送ったり並べ替えを変えたりしても、同じサンプルの中で動きます。

<Callout>
  データの表は draw したときのフィルターを使います。フィルターパネルで編集中の値は、draw を押すまで反映されません。
</Callout>

## リンクをコピー

タブツールバー右側の **リンクをコピー** を押すと、現在のチャートを共有として固定し、共有ページのリンクをコピーします。

- 設定、item ごとに変えた状態(拡大・図形・色など)、代表画像(選んだ item、なければ最初に描かれた item)をそのまま固定します。その後チャートを修正しても、共有は変わりません。
- リンクは `/share?id=…` の形です。

### 共有ページ

リンクを開くと、ログインした後に、固定された画像とタイトル・作成者・日時・データ・チャートの種類を表示します。

- **gallery で開く**: 新しい gallery タブで、同じ設定と item の状態で描き直します。
- **リンクをコピー**、**フィードに投稿**
- **削除**: 作成者だけが削除できます。削除したリンクは「存在しない共有」として開きます。

トップバーの **shares** を押すと、自分が作成した共有の一覧が表示されます。

<Callout tone="warn" title="同じブラウザでのみ開けます">
  現在はサーバーがブラウザ内にあるため、共有はその共有を作成したブラウザでのみ開けます。自分でアップロードしたデータで作成したチャートも同様です。
</Callout>

## フィードに投稿

**フィードに投稿** を押すと共有を作成し、データ共有フィードの投稿作成画面を新しいタブで開きます。タイトル・代表画像・共有リンクが入力されたチャートの投稿として始まります。投稿の「vis-a-lot でチャートを開く」を押すと、共有ページに戻ります。
