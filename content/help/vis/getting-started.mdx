vis-a-lot은 서버가 그린 PNG 차트를 브라우저에 띄우는 시각화 도구입니다. 데이터를 등록하고, 컬럼을 골라 차트를 그리고, 그린 차트를 살펴보고 공유합니다.

<Callout title="서버 없이 브라우저 안에서 동작합니다">
  이 프로토타입은 "서버"를 브라우저 안에서 돌립니다. 등록한 데이터와 history는 지금 쓰는 브라우저에만 저장됩니다. 자세한 내용은 [알아 두기](/help/vis/faq)를 보세요.
</Callout>

## 로그인

첫 화면에서 아이디와 비밀번호를 입력합니다. 데모 계정은 아이디 `demo`, 비밀번호 `demo1234`입니다.

한동안 요청이 없으면 세션이 끝나 다시 로그인해야 합니다. 로그아웃은 상단 바 오른쪽 사용자 메뉴에 있습니다.

## 시작 화면

로그인하면 아직 연 차트가 없으므로 시작 화면이 뜹니다. 카드 네 개 중 하나를 고르면 작업 화면으로 넘어갑니다.

| 카드 | 하는 일 |
| --- | --- |
| 새 차트 그리기 | gallery를 열어 차트를 그립니다 |
| 기록 다시 보기 | history를 열어 전에 그린 차트를 봅니다 |
| 데이터 올리기 | CSV·zip 파일을 올립니다 |
| 데이터 관리 | 등록된 데이터 목록(datastore)을 엽니다 |

## 화면 구성

```
┌ 상단 바: upload · datastore · gallery · history · shares · feed · help    테마 · 사용자 ┐
├ 탭 바: [차트 탭] [차트 탭] [+]                                              [필터] ┤
├ 탭 도구 줄: 모드 바 │ 차트 도구                         링크 복사 · 피드에 올리기 ┤
├ 왼쪽 패널 ─┬ 차트 grid ─────────────────────────┬ 페이지 스크롤바 ┬ 필터 패널 ┤
│ 데이터     │  [item] [item] [item]               │                 │            │
│ 차트 · 컬럼 │  [item] [item] [item]               │                 │            │
│ 전체 설정   ├ 하단 바: 진행 상황 ──────────────────┤                 │            │
│ draw       │                                     │                 │            │
└────────────┴─────────────────────────────────────┴─────────────────┴────────────┘
```

### 상단 바

앱 전체에 걸린 메뉴입니다.

- **upload**: 파일을 올려 데이터로 등록합니다. → [데이터 준비](/help/vis/data)
- **datastore**: 등록된 데이터 목록입니다. 샘플 데이터도 여기서 등록합니다.
- **gallery**: 차트를 그리고 편집하는 화면입니다.
- **history**: 전에 그린 차트를 다시 보는 화면입니다. → [history](/help/vis/history)
- **shares**: 내가 만든 공유 목록입니다. → [내보내기와 공유](/help/vis/export-share)
- **feed**: 데이터 공유 피드로 갑니다.
- **help**: 이 도움말을 엽니다.
- 오른쪽의 테마 버튼은 누를 때마다 시스템 → 라이트 → 다크 순으로 바뀝니다. 차트 PNG도 바뀐 테마로 다시 그립니다.

### 탭

gallery와 history 모두 탭으로 여러 차트를 열어 둡니다. 탭마다 데이터·설정·차트·진행 상황을 따로 가지고 있어서, 탭을 오가도 하던 작업이 그대로 남습니다.

- `+`로 새 gallery 탭을 엽니다. 마지막 탭 하나는 닫을 수 없습니다.
- 차트를 그리는 동안에는 탭을 바꿀 수 없습니다. cancel을 누르거나 다 그려질 때까지 기다리세요.

### 탭 도구 줄

그 탭의 차트에 쓰는 도구입니다. 왼쪽부터 **모드 바**(기본·이동·확대·선택·삭제·페인트), **차트 도구**(체크박스 표시·다운로드·데이터 테이블), 오른쪽 끝에 **링크 복사**와 **피드에 올리기**가 있습니다.

### 왼쪽 패널

데이터, 차트 종류, grid 크기, x·y 같은 컬럼, split by, tooltip을 고릅니다. 아래에 고정된 **전체 설정**과 **draw** 버튼은 설정을 스크롤해도 늘 보입니다.

### 차트 grid와 하단 바

그린 차트가 item 단위로 grid에 놓입니다. 오른쪽 페이지 스크롤바로 페이지를 넘기고, 아래 하단 바에서 진행률과 처리 속도를 봅니다.
