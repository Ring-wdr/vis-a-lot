그린 차트는 이미지·엑셀·CSV로 내려받거나, 링크로 공유하거나, 데이터 공유 피드에 올릴 수 있습니다.

## 차트 도구

탭 도구 줄 가운데의 차트 도구입니다. item 하나에 쓰는 도구는 먼저 item을 눌러 골라야 합니다.

| 도구 | 하는 일 | item 고르기 |
| --- | --- | --- |
| 체크박스 표시 | legend 항목에 체크박스를 띄워 값을 숨깁니다 → [꾸미기](/help/vis/customize#체크박스로-값-숨기기) | |
| 차트 다운로드 | 고른 item을 `이름.png`로 받습니다 | 필요 |
| 모든 차트 엑셀로 다운로드 | 모든 item의 PNG를 xlsx 한 파일에 담습니다 | |
| 데이터 다운로드 | 고른 item의 행을 CSV로 받습니다 | 필요 |
| 데이터 테이블 | 고른 item의 행을 표로 봅니다 | 필요 |
| 전체 데이터 테이블 | 데이터 전체를 표로 봅니다 (최대 30,000행 샘플) | |

### 모든 차트 엑셀로 다운로드

'차트' 시트에 grid와 같은 열 수로 item 이름과 이미지를 놓고, '목록' 시트에 순번·이름·상태를 적습니다. 파일 크기 때문에 앞에서부터 **300개**까지만 이미지를 넣습니다. 그리지 못한 item은 목록에만 남습니다.

### 데이터 테이블과 데이터 다운로드

고른 item에 쓰인 원본 행을 데이터의 모든 컬럼으로 봅니다.

- split 조합, draw할 때 적용한 필터, 체크박스로 숨긴 legend 값이 반영됩니다.
- 선택 영역이 있으면 그 안의 행만, 점을 지웠으면 지운 행을 뺀 나머지를 담습니다 (scatter·line·bar·boxplot·histogram·waterfall).
- 열 머리를 누르면 오름차순 → 내림차순 → 정렬 없음 순으로 바뀝니다.
- 데이터 다운로드는 같은 행을 Excel에서 바로 열리는 CSV로 받습니다. 선택 영역이 있으면 파일 이름에 `_선택`이 붙습니다.

### 전체 데이터 테이블

draw할 때 적용한 필터로 거른 데이터 전체를 봅니다. 행이 30,000개를 넘으면 30,000행만 무작위로 뽑아 보여 주고, 표 머리에 '전체 N행 중 30,000행 샘플'이라고 적습니다. 페이지를 넘기거나 정렬을 바꿔도 같은 샘플 안에서 움직입니다.

<Callout>
  데이터 표는 draw할 때의 필터를 씁니다. 필터 패널에서 고치고 있는 값은 draw를 누르기 전까지 반영되지 않습니다.
</Callout>

## 링크 복사

탭 도구 줄 오른쪽 **링크 복사**를 누르면 지금 차트를 공유로 고정하고 공유 페이지 링크를 복사합니다.

- 설정, item마다 바꾼 상태(확대·도형·색 등), 대표 이미지(고른 item, 없으면 처음 그려진 item)를 그대로 고정합니다. 이후 차트를 고쳐도 공유는 바뀌지 않습니다.
- 링크는 `/share?id=…` 모양입니다.

### 공유 페이지

링크를 열면 로그인한 뒤 고정된 이미지와 제목·만든 사람·시각·데이터·차트 종류를 보여 줍니다.

- **gallery에서 열기**: 새 gallery 탭에서 같은 설정과 item 상태로 다시 그립니다.
- **링크 복사**, **피드에 올리기**
- **지우기**: 만든 사람만 지울 수 있습니다. 지운 링크는 '없는 공유'로 열립니다.

상단 바의 **shares**를 누르면 내가 만든 공유 목록이 보입니다.

<Callout tone="warn" title="같은 브라우저에서만 열립니다">
  지금은 서버가 브라우저 안에 있어서, 공유는 그 공유를 만든 브라우저에서만 열립니다. 직접 올린 데이터로 만든 차트도 마찬가지입니다.
</Callout>

## 피드에 올리기

**피드에 올리기**를 누르면 공유를 만들고, 데이터 공유 피드의 게시물 쓰기 화면을 새 탭으로 엽니다. 제목·대표 이미지·공유 링크가 채워진 차트 게시물로 시작합니다. 게시물의 "vis-a-lot에서 차트 열기"를 누르면 공유 페이지로 돌아옵니다.
