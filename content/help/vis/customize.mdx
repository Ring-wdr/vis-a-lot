차트 모양은 모든 item에 함께 적용하는 **전체 설정**과, item 하나에만 적용하는 **item 속성**으로 바꿉니다.

## 전체 설정

왼쪽 패널 아래 **전체 설정**을 누르면 팝업이 열립니다. 왼쪽 메뉴에서 구역을 고르고 값을 바꾼 뒤 **확인**을 누릅니다.

<Callout title="다음 draw에 적용됩니다">
  전체 설정은 바로 다시 그리지 않습니다. 확인을 누른 뒤 draw를 눌러야 그린 차트에 반영됩니다. 바꾼 전체 설정으로 다시 그리면 item마다 따로 정한 속성은 모두 전체 설정 값으로 바뀝니다.
</Callout>

메뉴는 고른 차트 종류가 쓰는 구역만 보입니다.

| 구역 | 바꾸는 것 |
| --- | --- |
| 제목 | 제목·부제목 글자와 색, 정렬, 요약 표시, split item 이름을 잇는 문자 |
| 축 | X축·Y축 보이기, 제목, 최솟값·최댓값, 로그 축, 선·그리드·눈금·눈금 글자 |
| 범례 | legend 보이기, 위치(위·아래·왼쪽·오른쪽), 테두리, 순서 뒤집기, 글자 |
| 패널 | 배경 색, 그라데이션, 테두리, 여백 |
| 팔레트 | 기본 색, legend 값별 색, 그라데이션 색, 기타 색 |
| 모양 | 점 모양, 채우기 방식, 투명도, 테두리, 선택 밖 진하기, 막대 모서리 둥글기 |
| 크기 | 점 크기(자동·고정), 글자 크기(자동), 선 굵기 |
| 점 라벨 | 점 옆에 값 적기 (위치, 각도, 앞뒤 글자, 소수 자리) |
| 점수 | 상관계수, 분산분석 F, 규격 내 확률, 공정 능력(Cpk) |
| 예측 | 이동 평균·지수 평활로 다음 값을 예측해 신뢰 구간과 함께 그리기 |
| 값 | 빈 칸 값, 이상치 빼기(IQR·정규분포) |
| 강조 | 조건에 맞는 점·막대 강조 |
| 툴팁 | 가장 가까운 점 표시 (화면 표시만 바꿈) |
| 식 | x·y 값을 식으로 바꿔 그리기. 예: `log(y)`, `x * 2 + 1` |

## legend 색과 위치

legend는 서버가 PNG 안에 그립니다. 어느 item에서든 같은 값은 같은 색입니다.

- item 위에 커서를 올리고 legend 항목의 **●**를 누르면 색 선택기가 열립니다. 고른 색은 그 item에만 적용됩니다.
- 색은 item 속성 → 전체 설정 → 기본 팔레트 순으로 정해집니다. legend 위치도 같은 순서입니다.

### 체크박스로 값 숨기기

차트 도구의 **체크박스 표시**를 켜면 legend 항목 앞에 체크박스가 나타납니다. 체크를 풀면 그 item에서 그 값의 점·막대 등을 빼고 다시 그립니다. 숨긴 값은 history와 공유에도 남습니다.

## item 개별 속성

item 도구의 **item 속성**(⚙)을 누르면 전체 설정과 같은 구역을 그 item에만 적용하는 팝업이 열립니다. **확인**을 누르면 그 item만 바로 다시 그립니다.

- 범례 구역에서 legend 위치와 legend 값별 색을 바꿉니다. **공통 위치 따르기**·**공통 색 따르기**를 고르면 전체 설정 값을 씁니다.
- 구역마다 **이 구역은 공통 속성 따르기**, 아래의 **모두 공통 속성 따르기**로 전체 설정 값으로 되돌립니다.
- item 속성을 바꾼 구역은 메뉴 이름 뒤에 •가 붙습니다.
- item 속성은 history와 공유에도 남습니다.

## 다크 모드

상단 바의 테마 버튼으로 시스템·라이트·다크를 고릅니다. 차트 PNG도 같은 테마로 다시 그리고, 차트 다운로드도 보고 있는 테마로 받습니다.
