vis-a-lot は、サーバーが描いた PNG チャートをブラウザに表示する可視化ツールです。データを登録し、カラムを選んでチャートを描き、描いたチャートを調べて共有します。

<Callout title="サーバーなしでブラウザ内で動作します">
  このプロトタイプは「サーバー」をブラウザ内で動かします。登録したデータと history は、いま使っているブラウザにのみ保存されます。詳しくは [知っておくこと](/help/vis/faq) をご覧ください。
</Callout>

## ログイン

最初の画面で ID とパスワードを入力します。デモアカウントは ID `demo`、パスワード `demo1234` です。

しばらくリクエストがないとセッションが終了し、もう一度ログインする必要があります。ログアウトはトップバー右側のユーザーメニューにあります。

## スタート画面

ログイン直後はまだ開いているチャートがないため、スタート画面が表示されます。4 つのカードのいずれかを選ぶと作業画面に移ります。

| カード | できること |
| --- | --- |
| 新しいチャートを描く | gallery を開いてチャートを描きます |
| 履歴を見直す | history を開いて以前に描いたチャートを見ます |
| データをアップロード | CSV・zip ファイルをアップロードします |
| データ管理 | 登録済みデータの一覧(datastore)を開きます |

### トップバー

アプリ全体に共通のメニューです。

- **upload**: ファイルをアップロードしてデータとして登録します。→ [データの準備](/help/vis/data)
- **datastore**: 登録済みデータの一覧です。サンプルデータもここで登録します。
- **gallery**: チャートを描いて編集する画面です。
- **history**: 以前に描いたチャートを見直す画面です。→ [history](/help/vis/history)
- **shares**: 自分が作成した共有の一覧です。→ [エクスポートと共有](/help/vis/export-share)
- **feed**: データ共有フィードに移動します。
- **help**: このヘルプを開きます。
- 右側のテーマボタンは、押すたびにシステム → ライト → ダークの順に切り替わります。チャートの PNG も切り替えたテーマで描き直します。

### タブ

gallery と history はどちらも、タブで複数のチャートを開いておけます。タブごとにデータ・設定・チャート・進行状況を別々に持つため、タブを切り替えても作業はそのまま残ります。

- `+` で新しい gallery タブを開きます。最後の 1 つのタブは閉じられません。
- チャートを描いている間はタブを切り替えられません。cancel を押すか、描き終わるまでお待ちください。

### タブツールバー

そのタブのチャートに使うツールです。左から **モードバー**(基本・移動・拡大・選択・削除・ペイント)、**チャートツール**(チェックボックス表示・ダウンロード・データテーブル)、右端に **リンクをコピー** と **フィードに投稿** があります。

### 左パネル

データ、チャートの種類、grid のサイズ、x・y などのカラム、split by、tooltip を選びます。下部に固定された **全体設定** と **draw** ボタンは、設定をスクロールしても常に表示されます。

### チャート grid とボトムバー

描いたチャートは item 単位で grid に配置されます。右側のページスクロールバーでページを送り、下のボトムバーで進行率と処理速度を確認します。
