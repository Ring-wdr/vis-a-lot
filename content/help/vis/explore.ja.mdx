描いたチャートはツールチップで値を読み取り、タブツールバーの **モードバー** で拡大・選択・図形などの操作をします。操作は item ごとに別々に適用され、操作した item だけをサーバーが描き直します。

## ツールチップ

item の上にカーソルを合わせるとツールチップが表示されます。最初にカーソルを合わせたときだけ少し待ち、その後はすぐに表示されます。

| チャート | ツールチップの内容 |
| --- | --- |
| Scatter · Line | カーソル位置の x・y の値と最も近い点 |
| Bar · Pie · Treemap など | 指している棒・スライスの値 |
| Boxplot | 四分位数などの統計値 |
| Histogram | 区間の範囲と件数 |
| Candle | 区間・始値・高値・安値・終値・件数 |
| Gantt | 行・legend の値・開始・終了・長さ |

左パネルの **tooltip** で選んだカラムは、最も近い点(行)の値として一緒に表示されます。scatter・line の最も近い点の表示は、全体設定のツールチップメニューでオフにできます。

## モードバー

オンにできるモードは 1 つだけです。チャートを描く前や history で見直すときは、**基本** モードだけを使えます。

| モード | できること |
| --- | --- |
| 基本 | ツールチップを見ます |
| 移動 | チャートをドラッグして表示範囲を動かします。離すと動かした範囲で描き直します |
| 拡大 | ドラッグして選んだ領域に拡大します |
| 矩形選択 · 自由形選択 | ドラッグして領域を選びます。領域の外は薄く描き、タイトル行に選択した数を記します |
| 矩形削除 · 自由形削除 | 選んだ領域の点をその item から除きます(scatter・line) |
| ペイント | チャートの上に図形とメモを描きます |

チャートごとに使えるモードは [チャートの種類](/help/vis/chart-types#ja-チャートごとに使えるツール) にまとめています。

### 拡大と縮小

拡大モードで領域をドラッグして選ぶと、その範囲で描き直します。日時の軸も、ごく狭い範囲まで拡大できます。item 右上のツールの **縮小** は決まった比率だけ縮小し、**拡大をリセット** は最初の範囲に戻します。

### 領域の選択

選択モードでドラッグせずにクリックすると選択を解除します。選択領域は item ごとに 1 つです。選択した領域で右クリックするとメニューが開きます。

| メニュー | できること |
| --- | --- |
| お気に入りに追加… | 現在の領域に名前を付けて保存します |
| 新しい凡例… | 領域内の点を新しい legend 項目で塗ります(8 個まで) |
| 選択を解除 | 選択を解除します |
| お気に入りを選択 ▸ | 保存した領域を再び選びます |
| お気に入りを削除 ▸ | 保存した領域を削除します |
| 削除した点をすべて戻す | 点の削除で除いた点をすべて戻します |
| 新しい凡例を削除 ▸ | 作成した legend 項目を削除します |

選択領域がある場合、データテーブルとデータのダウンロードにはその中の行だけが含まれます(scatter・line・bar・boxplot・histogram・waterfall)。

### 点の削除

矩形削除・自由形削除モードで選んだ領域の点を、その item から除きます。元のデータはそのままで、画像・点の数・ツールチップからだけ除かれます。item ツールの **削除した点を戻す** は最後の領域を、右クリックメニューの **削除した点をすべて戻す** はすべてを戻します。

### ペイント

ペイントモードでは、item の左上に描画ツールが表示されます。

- **四角形 · 線 · フリーハンド · テキスト** から選びます。タブ内のすべての item が同じツールを使います。
- マウスを離すと保存し、その item を描き直します。図形はデータ座標で保存されるため、拡大しても同じ位置に付いたままです。
- 描いた図形は編集できません。**図形を元に戻す**(最後の図形を削除)と **図形をすべて削除** だけがあります。

## item ツール

item の上にカーソルを合わせると、右上にツールが表示されます。

- **縮小**、**拡大をリセット**
- **削除した点を戻す**(点を削除したとき)
- **item 属性**: この item にだけ適用する属性(legend の位置・色など)を変更します。→ [装飾](/help/vis/customize#ja-item-ごとの属性)
- **拡大表示**

## 拡大表示

item をダブルクリックするか **拡大表示** を押すと、grid の場所にその item 1 つを大きく表示します。拡大表示した item でも、ツールチップ・拡大・図形・色の操作が同じようにできます。

- 下のサムネイル列で別の item を選びます。
- <Kbd>←</Kbd> <Kbd>→</Kbd>: 前・次の item、<Kbd>Home</Kbd> <Kbd>End</Kbd>: 最初・最後の item
- もう一度ダブルクリックするか、<Kbd>Esc</Kbd> や **grid に戻る** を押すと、その item があるページに戻ります。

## item を選ぶ

item を押すと枠が強調され、その item を選んだ状態になります。チャートのダウンロード・データのダウンロード・データテーブルのように item 1 つに使うツールは、item を選んでから使えます。新しく draw すると、選んだ item は解除されます。
