gallery 탭의 왼쪽 패널에서 데이터와 컬럼을 고르고 **draw**를 누르면 차트를 그립니다. 설정을 바꿔도 자동으로 다시 그리지 않으므로, 바꾼 뒤에는 draw를 눌러야 합니다.

## 왼쪽 패널

| 항목 | 내용 |
| --- | --- |
| 데이터 | 등록한 데이터 중 하나를 고릅니다. 데이터를 바꾸면 새 데이터에 맞지 않는 컬럼 설정은 타입에 맞는 기본값으로 바뀝니다 |
| 차트 | 차트 종류를 고릅니다. → [차트 종류](/help/vis/chart-types) |
| 서브 차트 | line·bar·boxplot·pie에만 있는 세부 모양입니다 |
| grid | 한 페이지에 놓을 item의 행 × 열입니다 |
| x · y · z | 차트에 쓸 컬럼입니다. 차트 종류에 따라 고를 수 있는 컬럼 타입이 다릅니다 |
| legend | 색을 나눌 범주 컬럼입니다. 고유값이 8개 이하인 범주 컬럼만 고를 수 있습니다 |
| 통계 함수 | y 값을 모을 방법입니다: 평균·합계·개수·최솟값·최댓값·중앙값. 값을 모으는 차트에서만 보입니다 |
| split by | 차트를 나눌 컬럼입니다. 여러 개를 고를 수 있습니다 |
| tooltip | 툴팁에 함께 보일 컬럼입니다. 여러 개를 고를 수 있습니다 |

## split by와 grid

**split by**에 컬럼을 고르면 그 컬럼 값마다 차트를 하나씩(item) 따로 그립니다. 여러 컬럼을 고르면 값의 모든 조합마다 item이 생깁니다.

- 고른 순서가 item 이름 순서가 됩니다. 공장 → 근무조 순으로 고르면 item 이름은 `울산-주간`처럼 붙습니다. 이름을 잇는 문자는 전체 설정의 제목 메뉴에서 바꿉니다.
- 목록에서 항목을 누른 채 끌면 지나간 순서대로 한꺼번에 고릅니다.
- item은 최대 **30,000개**까지 그립니다. 넘으면 draw 전에 알리고 그리지 않습니다. 필터를 걸었다면 필터를 적용한 개수로 셉니다.

**grid**는 10 × 10 칸에서 행 × 열을 고릅니다(1 × 1 ~ 10 × 10). item이 한 페이지보다 많으면 여러 페이지로 나뉩니다. 예를 들어 3 × 3 grid에 item이 20개면 3페이지입니다.

<Callout>
  grid 크기를 바꾸면 item 크기가 달라지므로 draw를 누르지 않아도 바로 전체를 다시 그립니다. 그리는 중에는 grid 크기를 바꿀 수 없습니다.
</Callout>

## draw와 cancel

draw 버튼은 그리는 동안 상태가 바뀝니다.

1. **draw**를 누르면 잠깐 비활성 상태로 요청을 보냅니다.
2. 그리기가 시작되면 버튼이 **cancel**로 바뀝니다. 누르면 아직 그리지 못한 item을 취소합니다.
3. 다 그리면 다시 **draw**가 됩니다.

다 그려진 item부터 화면에 나타나고, 그 item은 바로 툴팁·확대 같은 조작을 할 수 있습니다. 그리지 못한 item에는 오류 표시가 남습니다.

데이터가 아직 적재 중이면 적재가 끝날 때까지 기다렸다가 그립니다.

## 하단 바

grid 아래 하단 바에 진행 상황이 보입니다.

- 지금 단계와 진행률(%)
- 상태별 item 수: 완료 · 그리는 중 · 대기 · 실패 · 취소
- 지난 시간, 처리 속도(item/s), 남은 시간 어림

## 페이지 넘기기

grid 오른쪽 페이지 스크롤바로 페이지를 넘깁니다. 그리는 중에도 넘길 수 있고, 페이지를 넘겨도 그리기는 멈추지 않습니다.

- 위·아래 화살표: 한 페이지씩 (누르고 있으면 계속)
- 트랙: 누른 쪽으로 이동
- thumb: 끌어서 이동
- 마우스 휠, 키보드 <Kbd>↑</Kbd> <Kbd>↓</Kbd> <Kbd>PageUp</Kbd> <Kbd>PageDown</Kbd> <Kbd>Home</Kbd> <Kbd>End</Kbd>

## 창 크기를 바꾸면

창 크기를 바꾸고 잠시 기다리면 지금 페이지의 item만 새 크기로 다시 그립니다. 다시 그리는 동안에는 이전 그림을 늘리거나 줄여 보여 줍니다.
