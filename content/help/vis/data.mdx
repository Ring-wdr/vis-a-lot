차트를 그리려면 먼저 데이터를 등록해야 합니다. 등록한 데이터만 왼쪽 패널의 **데이터**에서 고를 수 있습니다.

## 샘플 데이터 등록하기

제조/IoT 센서 데이터를 샘플로 제공합니다. 행 수에 따라 10만·50만·100만 행 세 가지가 있습니다.

1. 상단 바에서 **datastore**를 엽니다.
2. 목록 맨 아래의 샘플 중 하나에서 **등록**을 누릅니다.
3. 상태가 **준비됨**이 되면 쓸 수 있습니다. 한 번 만든 데이터는 브라우저에 남아 다음에 다시 만들지 않습니다.

샘플 데이터의 컬럼은 다음과 같습니다.

| 컬럼 | 타입 | 설명 |
| --- | --- | --- |
| 측정 시각 (`ts`) | 시계열 | 30일 동안의 측정 시각 |
| 공장 (`factory`) | 범주 | 3개 |
| 라인 (`line`) | 범주 | 공장마다 4개 |
| 설비 (`machine`) | 범주 | 약 120개 |
| 센서 종류 (`sensor_type`) | 범주 | 온도·진동·압력·전류 |
| 근무조 (`shift`) | 범주 | 주간·야간·심야 |
| LOT (`lot_id`) | 범주 | 약 5,000개 |
| 상태 (`status`) | 범주 | 정상·경고·이상 |
| 측정값 (`value`) | 숫자 | 하루 주기 변동, 설비별 drift, 이상 구간이 섞인 값 |
| 주변 온도 (`temperature_env`) | 숫자 | 측정값과 상관관계가 있습니다 |
| 부하율(%) (`load_pct`) | 숫자 | 설비 부하율 |

## 내 파일 올리기

상단 바의 **upload**(또는 시작 화면의 데이터 올리기)로 CSV 파일 하나나 CSV를 묶은 zip을 올립니다.

1. **파일 선택**으로 파일을 고릅니다. zip이면 왼쪽에 안의 CSV 목록이 보입니다.
2. 오른쪽 **전처리 옵션**을 맞춥니다. 옵션을 바꾸면 잠시 뒤 아래 미리보기가 바뀝니다.
3. 미리보기 표 머리에서 넣을 컬럼(체크)과 타입을 정합니다.
4. 필요하면 **검사**로 파일 전체를 미리 확인합니다.
5. **확인**을 누르면 적재가 시작되고, 아래 줄에 진행 상황이 보입니다. 끝나면 datastore 팝업으로 넘어갑니다.

### 전처리 옵션

| 옵션 | 내용 |
| --- | --- |
| 구분 기호 | 쉼표·탭·세미콜론·세로 막대, 또는 한 글자 직접 입력 |
| 첫 번째 행 헤더 | 끄면 컬럼 이름이 `column_1`, `column_2`…가 됩니다 |
| Null 값 | 이 값과 같은 칸을 빈 값(null)으로 읽습니다. 기본은 빈 칸입니다 |
| 따옴표 | 값을 감싼 따옴표 한 글자. 기본은 `"`입니다 |
| 날짜 시간 형식 | `자동 (ISO 8601)` 또는 `yyyy-MM-dd HH:mm:ss` 같은 패턴. 이 형식으로 읽히는 컬럼을 시계열로 봅니다 |
| 데이터 오류 무시 | 켜면 타입에 맞지 않는 값은 null로 넣고, 칸 수가 맞지 않는 행은 건너뜁니다. 끄면 그런 값이 있을 때 사유와 함께 거절합니다 |
| 인코딩 | 자동(UTF-8, 깨지면 EUC-KR), UTF-8, EUC-KR |

### 컬럼 타입

타입은 값을 보고 자동으로 정합니다. 모두 숫자면 **숫자**, 모두 날짜 시간 형식으로 읽히면 **시계열**, 나머지는 **범주**입니다. 미리보기 표 머리 둘째 줄에서 컬럼마다 직접 바꿀 수 있고, 정한 타입으로 바꿀 수 없는 칸은 빨갛게 표시됩니다.

컬럼 타입은 차트에서 그 컬럼을 어디에 쓸 수 있는지 정합니다. 예를 들어 bar의 x에는 범주 컬럼만, y에는 숫자 컬럼만 고를 수 있습니다. → [차트 종류](/help/vis/chart-types)

### 검사

**검사**는 적재하지 않고 파일 전체를 읽어 행 수와 컬럼별로 바꿀 수 없는 값의 수를 알려 줍니다. 큰 파일은 적재 전에 검사해 보는 것이 좋습니다.

### zip 파일

zip 안의 CSV(하위 폴더 포함)는 이름순으로 **한 데이터로 합칩니다**. CSV가 아닌 파일은 건너뜁니다. CSV끼리 컬럼 수·이름·타입이 하나라도 다르면 전체를 거절하고, 어느 파일의 어느 컬럼이 다른지 알려 줍니다.

<Callout tone="warn" title="한도">
  압축을 푼 크기 300MB, CSV 500개, 컬럼 200개까지 올릴 수 있습니다.
</Callout>

## datastore

등록된 데이터 목록입니다. 올린 데이터가 위(최근 순), 샘플이 맨 아래에 있습니다.

- 이름으로 검색합니다.
- 데이터를 고르고 **gallery에서 열기**(또는 더블 클릭)를 누르면 그 데이터로 새 gallery 탭이 열립니다.
- **수정**: 같은 업로드 팝업이 수정 모드로 열립니다. 이름·옵션·타입·포함 컬럼을 바꿔 **다시 적재**합니다. 원본 파일은 바꿀 수 없고, 다시 적재가 거절되면 기존 데이터를 그대로 둡니다.
- **삭제**: 올린 데이터를 지웁니다. 샘플은 수정·삭제할 수 없고, 적재 중인 데이터도 지울 수 없습니다.
