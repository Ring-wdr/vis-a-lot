Change how charts look with **Settings**, which apply to every item, and **item settings**, which apply to a single item.

## Settings

Press **Settings** at the bottom of the left panel to open a popup. Pick a section in the menu on the left, change values and press **OK**.

<Callout title="Applies on the next draw">
  Settings don't redraw right away. Press draw after OK to apply them to the drawn charts. When you redraw with changed settings, every per-item setting is replaced by the Settings values.
</Callout>

The menu shows only the sections used by the selected chart type.

| Section | What it changes |
| --- | --- |
| Title | Title and subtitle text and color, alignment, subtitle font size and alignment, summary display, the character joining split item names |
| Axes | Show the X and Y axes, titles, min and max, log axes, lines, grid, ticks and tick labels, category sort and order (X axis) |
| Legend | Show the legend, position (top, bottom, left, right), border, sort and order, reverse order, text |
| Panel | Background color, gradient, border, padding |
| Palette | Base color, colors per legend value, gradient colors, other color, color list |
| Shape | Point shape (10 kinds), fill style, opacity, outline, intensity outside the selection, bar corner radius |
| Size | Point size (auto or fixed), text size (auto), line width |
| Point labels | Write values next to points (position, angle, prefix and suffix, decimals) |
| Scores | Correlation, ANOVA F, probability within spec, process capability (Cpk) |
| Forecast | Predict the next values with a moving average or exponential smoothing and draw them with a confidence band |
| Values | Value for empty cells, excluding outliers or showing outliers only (IQR, normal distribution) |
| Highlight | Highlight points and bars by condition, rank or range |
| Control limits | Reference lines, column lines and bands, highlighting out-of-spec (USL, LSL) marks, the spec area → [Control limits](#en-control-limits) |
| Tooltip | Show the nearest point (changes the display only) |
| Selection values | Fields (up to 3) and separator for selection values. Doesn't change the image → [Selection values](/help/vis/explore#en-selection-values) |
| Expression | Draw x and y transformed by an expression, e.g. `log(y)`, `x * 2 + 1` |

## Changing the order

Set the order of legend entries and of the categories on the x axis yourself. Change it in **Sort** and **Order** in the legend section, and in **Category sort** and **Category order** under Axes › X axis.

- The **Order** field lists the values in their current order. Drag a value, or focus it and press <Kbd>Alt</Kbd>+<Kbd>↑</Kbd> <Kbd>↓</Kbd> to move it one step. Everything from the top of the list down to the last value you moved is saved as the order (it gets numbers), and the remaining values follow in **Sort** order.
- **Sort** is **Default (value order)** or **Natural**. Natural compares numbers inside the text as numbers, giving `L1, L2, L10`.
- **Reset order** clears the order you set.
- Values in the order that an item doesn't have are skipped.
- **Colors don't change.** Colors still follow the value, so the same value keeps its color when you change the order.
- **Reverse order** reverses only the entries in the legend box.

| Order | What changes | Charts |
| --- | --- | --- |
| Legend order | Legend box entries, bars and boxes side by side within a category, stacking order, bars within a histogram bin, drawing order of radar polygons and line series | Charts where you pick a legend column (scatter, line, bar, boxplot, histogram, radar, gantt, treemap) |
| Category order | x-axis categories with their bars, boxes and cells. Waterfall accumulates in the new order | bar, boxplot, waterfall, heatmap (x only) |

A column with more than 200 unique values can't be ordered; you can only pick the sort.

## Highlight methods

Pick a **Method** in the highlight section to show only the fields for that method. **Target** (x value, y value), color, shape, size and **Single color for the rest** are shared by all three methods.

| Method | What is highlighted |
| --- | --- |
| Condition | Values matching an operator (`>` `>=` `<` `<=` `=` `!=`) and a value |
| Rank | The set number (1–1,000) from the largest (or smallest) values |
| Range | Values between min and max. Both ends are included, and an empty end has no limit |

- Rank uses **all** points, bars and boxes the item draws, regardless of the zoom range. Legend values turned off with checkboxes, deleted points and excluded outliers are left out. Every value equal to the boundary is highlighted, so there can be more than the set number.
- For gantt the y value is the length (time) of a task bar, and for candle it is the close.

## Control limits

Draw references such as upper and lower spec limits, targets or average levels as lines on scatter, line and bar charts, and highlight points and bars outside the spec. Set them in the **Control limits** menu of Settings and of item settings. The **Control limits** button in the chart tools opens Settings at the control limits menu (view only in the history tab).

### Adding lines

Under **Lines**, pick a **Line type to add** and press **Add line**. Each line has a name, axis, color, width and style (solid, dashed, dotted), and the up and down buttons change the order. You can have up to 10 lines, names up to 40 characters, and no two lines may share a name. Names are drawn on the PNG exactly as written.

| Type | Fields | Value drawn |
| --- | --- | --- |
| Reference line | Value (a time on the Bottom axis of a time-series x), Spec | The value you enter |
| Column line | Column, Function (mean, max, median, min), Spec, Per interval | The value aggregated from the item's rows |
| Band | Column 1, Column 2, Per interval | Two lines, the mean of each column, with the space between them filled |

- Only numeric columns can be picked, and the two columns of a band must differ.
- Column lines and bands are aggregated from the rows of the item's split combination with the filters applied at draw time. Legend values turned off with checkboxes and deleted points are included, so checking a box does not move the lines.
- A line whose value cannot be computed (no rows, or all empty) is not drawn for that item.
- If a line doesn't fit, the reason appears under it and **OK** is disabled.
- Lines keep the color you chose, even in dark mode. Lines and out-of-spec highlighting are also drawn in chart downloads, Excel and shared images.

### Supported charts

| Chart | Left axis (y) | Bottom axis (x) |
| --- | --- | --- |
| Scatter, Line | Reference line, column line, band | Reference line, column line, band for a numeric x; reference line for a time-series x |
| Bar (Side) | Reference line, column line | |
| Bar (Stack, Stack 100) | Reference line | |

- Other charts and Line's ECDF, NCDF and Probability have no control limits menu. The **Control limits** button in the chart tools is dimmed when the drawn chart or the chart of the next draw doesn't use control limits; hover over it to see why.
- A column line on Bar is one line aggregated over all of the item's rows. Stacked bars compare the stacked end value with the lines, and Stack 100 values are percentages.

### Spec (USL, LSL) and out of spec

Pick USL (upper) or LSL (lower) in the **Spec** of reference and column lines. **Each axis can have only one USL and one LSL**. Bands have no spec.

- **Highlight out of spec** (on by default): points and bars whose y (for a Left axis spec) or x (for a Bottom axis spec) is above the USL or below the LSL are repainted in the **Out-of-spec color**. A value equal to the USL or LSL is not out of spec. If the USL is lower than the LSL, that axis is not checked.
- With a spec line, the title line shows `이탈 N` (out of spec), even when N is 0. It counts every drawn point and bar regardless of zoom, without values turned off with checkboxes or deleted points.
- Line charts check every point, not just the reduced line, and mark out-of-spec points as dots.
- With Highlight, highlighted points are drawn over out-of-spec points. Lines are not dimmed by a selection.
- If the upper and lower limits in the Scores section are empty, probability within spec and Cpk use the Left axis USL and LSL (not per interval). Values you enter there come first.

### Spec area

Turn on **Fill area** to paint by **Fill side**. **Inside spec** is between the LSL and USL (with only one, from that line to the edge of the plot on the inside), **Outside spec** is above the USL and below the LSL. Set the **Area color** and **Transparency** (0 opaque to 1 fully transparent, default 0.8). The area and band fills sit under the points.

### Per interval (step line)

Turn on **Per interval (step line)** for a Left axis column line or band on scatter or line to draw a spec that changes along x as steps.

- The x min to max of all filtered data (every split combination) is split into **240 equal intervals** and each interval is aggregated, so every item uses the same interval edges.
- The line breaks at intervals without a value, and points in those intervals are not checked. Rows without x are left out of per-interval aggregation.
- Intervals are fixed on the first draw and don't change when you zoom.
- A per-interval USL or LSL fills the area interval by interval. The label at the end of the line shows the value of the rightmost interval.

### Reference lines on a time-series x

When x is a time series, the Bottom axis takes only reference lines, and the value is entered in Korea time in the **Time (KST)** field. Use it to mark a single moment, such as an equipment change or a shift. The time in the line label uses the date format of Axes › X axis (empty: `year-month-day hour:minute`).

### Line labels and axis range

- **Show line names and values** (on by default): writes `name value` at the end of the line (`name smaller ~ larger` for a band). Left axis lines are labeled above the right end, Bottom axis lines beside the top end; labels move aside when they overlap other labels and are skipped when there is no room. An empty text color uses the tick label color, and the font size is used only when Size › Font size Auto is off. Thumbnails have no labels.
- **Extend axis range to show lines** (on by default): when not zoomed, widens the axis range so lines outside the data are visible. A min or max set in the Axes section comes first. While zoomed, the zoomed range stays, so lines and labels outside it are not shown.
- On a log axis, lines with values of 0 or less (or those intervals of a per-interval line) are not drawn.

### With expressions

When the Expression section transforms x or y, lines are drawn in the transformed coordinates too.

- Reference lines are taken as values read off the transformed axis and drawn as entered.
- The axis expression is applied to column line and band values and to interval edges. If the expression uses the other axis variable (for example `x` in the y expression), column lines and bands are not drawn.
- Out-of-spec checks, tooltip values, line labels and the Scores limits all use the transformed values.

### Item settings and lines that no longer fit

- A line list set in item settings replaces the Settings list for that item. Deleting every line leaves only that item without lines. Reset the section to common settings to go back to the Settings list.
- Changing the dataset, chart type or sub type, or x removes lines in Settings that no longer fit: lines using missing or non-numeric columns, and types the axis can't use (for example column lines when Bar Side becomes Stack, or column lines and numeric reference lines on the Bottom axis when x becomes a time series). Switching to Bar, which has no per-interval lines, only turns per interval off. Things you need to fix yourself, such as duplicate names or USLs, stay and show their reason. Switching to a chart without control limits keeps the lines without drawing them.
- If item settings restored from history or a share contain lines that don't fit the current chart, only those lines are left out and the rest are drawn.

## Point shapes

Pick from 10 shapes in **Default shape** in the shape section and **Shape** in the highlight section: circle, square, triangle, diamond, cross, down triangle, left triangle, right triangle, hexagon and star. Points in the PNG, legend markers and tooltip markers use the same shape.

## Showing outliers only

Turn on **Handle outliers** in the values section to choose **Outlier handling**. What counts as an outlier is set by **Outlier method** (IQR or normal distribution) and **k**.

| Chart | Exclude outliers | Outliers only |
| --- | --- | --- |
| Scatter · Line | Draws without points whose y is out of range. The title line shows how many were excluded | Draws only the out-of-range points, and the title line notes it |
| Bar | Removes out-of-range bars (aggregated values) | Keeps only the out-of-range bars |
| Boxplot | Removes the outlier points and draws only the boxes | Draws only the outlier points, without boxes or whiskers |

## Palette color list

Add up to 8 colors to **Color list** in the palette section to use them in legend value order instead of the 8 default palette colors. When there are more values than colors, the colors repeat from the first. **Use default palette** clears the list.

- Colors set per legend value (item settings, Settings) come before the color list.
- When **Use gradient colors** is on, the gradient comes before the color list.

## Subtitle size and alignment

**Subtitle font size** and **Subtitle align** in the title section follow the title when left empty (the size is 0.9 times the title size). Like the title font size, the font size is used only when Size › Font size Auto is off.

## Legend colors and position

The server draws the legend inside the PNG. The same value has the same color in every item.

- Hover over an item and press the **●** of a legend entry to open a color picker. The color you pick applies only to that item.
- Colors are decided in the order item settings → Settings → default palette. Legend position follows the same order.

### Hiding values with checkboxes

Turn on **Show checkboxes** in the chart tools to put checkboxes in front of legend entries. Uncheck one to redraw that item without that value's points, bars and so on. Hidden values are kept in history and shares too.

## Per-item settings

Press **Item settings** (⚙) in the item tools to open a popup with the same sections as Settings, applied only to that item. Press **OK** to redraw just that item right away.

- In the legend section, change the legend position and colors per legend value. Choosing **Use common position** or **Use common color** uses the Settings values.
- **Use common settings for this section** in each section, and **Use common settings for all** at the bottom, reset to the Settings values.
- Sections with item settings changed get a • after the menu name.
- Item settings are kept in history and shares too.

## Dark mode

Pick system, light or dark with the theme button in the top bar. Chart PNGs are redrawn in the same theme, and chart downloads use the theme you are viewing.
