## データと記録はどこに保存されますか?

vis-a-lot はサーバーなしで、ブラウザ内で「サーバー」を動かします。登録したデータ(サンプル・アップロード)、history、共有はすべて **いま使っているブラウザのストレージ** に残ります。

- 別のブラウザや端末からは見えません。
- ブラウザのサイトデータを削除すると、一緒に削除されます。
- datastore のポップアップ下部でストレージ使用量を確認できます。

## 再読み込みすると描いたチャートが消えます

描いている途中のチャートと作業状態はメモリ上にしかないため、再読み込みすると消えます。代わりに draw するたびに history に残るので、history から開き直して **gallery で編集** で続きの作業をしてください。

## 設定を変えたのにチャートが変わりません

チャートの設定、フィルター、全体設定は **draw** を押すと反映されます。grid のサイズ変更と item 属性、ウィンドウのサイズ変更だけがすぐに描き直されます。

## タブが切り替わりません

チャートを描いている間はタブを切り替えられません。**cancel** を押すか、描き終わるまでお待ちください。

## カラムが一覧に表示されません

- チャートの種類ごとに使えるカラムの型が異なります。→ [チャートの種類](/help/vis/chart-types)
- legend には、固有値が 8 個以下のカテゴリのカラムだけを選べます。
- アップロードしたデータの型が想定と違う場合は、datastore の **編集** でカラムの型を変えて再読み込みしてください。

## 一部のツールボタンが薄く表示されます

描いたチャートの種類では使えないモード・ツールです。ボタンにカーソルを合わせると理由が表示されます。history で見直している間や、まだ描いたチャートがないときも、基本モードだけを使えます。

## 上限

| 項目 | 上限 |
| --- | --- |
| split by の item 数 | 30,000 個 |
| grid | 10 × 10 |
| legend の値 | 8 個(パレットの色数) |
| 新しい凡例 | item ごとに 8 個 |
| アップロードするファイル | 展開後 300MB、CSV 500 個、カラム 200 個 |
| Excel でダウンロード | 画像 300 個 |
| 全データテーブル | 30,000 行のサンプル |
