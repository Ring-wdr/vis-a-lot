Drawn charts can be downloaded as images, Excel or CSV, shared by link, or posted to the data sharing feed.

## Chart tools

The chart tools in the middle of the tab toolbar. For tools that work on one item, click an item to pick it first.

| Tool | What it does | Pick an item |
| --- | --- | --- |
| Show checkboxes | Shows checkboxes on legend entries to hide values → [Customizing](/help/vis/customize#en-hiding-values-with-checkboxes) | |
| Download chart | Saves the picked item as `name.png` | Required |
| Download all charts as Excel | Puts the PNGs of all items in one xlsx file | |
| Download data | Saves the picked item's rows as CSV | Required |
| Data table | Shows the picked item's rows as a table | Required |
| Full data table | Shows all the data as a table (sample of up to 30,000 rows) | |

### Download all charts as Excel

The 'Charts' sheet places item names and images in as many columns as the grid, and the 'List' sheet lists the number, name and status. Because of file size, images are included only for the first **300** items. Items that failed to draw appear only in the list.

### Data table and data download

Shows the source rows used by the picked item, with every column of the data.

- The split combination, the filters applied at draw time, and legend values hidden with checkboxes are reflected.
- With a selection, only the rows inside it; with deleted points, the rest without the deleted rows (scatter, line, bar, boxplot, histogram, waterfall).
- Clicking a column header cycles ascending → descending → unsorted.
- Data download saves the same rows as a CSV that opens directly in Excel. With a selection, the file name gets a `_selection` suffix.

### Full data table

Shows all the data filtered by the filters applied at draw time. With more than 30,000 rows, 30,000 rows are sampled at random, and the table header says 'Sample of 30,000 out of N rows'. Paging or sorting moves within the same sample.

<Callout>
  Data tables use the filters from draw time. Values you are still editing in the filter panel aren't reflected until you press draw.
</Callout>

## Copy link

Press **Copy link** on the right of the tab toolbar to freeze the current chart as a share and copy the share page link.

- The settings, per-item changes (zoom, shapes, colors and so on) and a cover image (the picked item, or the first drawn item) are frozen as they are. Later edits to the chart don't change the share.
- Links look like `/share?id=…`.

### Share page

Opening a link shows, after sign-in, the frozen image with the title, creator, time, data and chart type.

- **Open in gallery**: Redraws with the same settings and item state in a new gallery tab.
- **Copy link**, **Post to feed**
- **Delete**: Only the creator can delete. A deleted link opens as 'share not found'.

Press **shares** in the top bar to see the shares you created.

<Callout tone="warn" title="Opens only in the same browser">
  For now the server lives inside the browser, so a share opens only in the browser that created it. The same goes for charts made from data you uploaded.
</Callout>

## Post to feed

Press **Post to feed** to create a share and open the post editor of the data sharing feed in a new tab. It starts as a chart post with the title, cover image and share link filled in. "Open chart in vis-a-lot" on the post brings you back to the share page.
