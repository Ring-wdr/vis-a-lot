analytics は、複数のチャートを 1 つの画面でパネルに分けて一緒に見る画面です。トップバーの **analytics** か、スタート画面の **複数のチャートを並べて見る** カードで開きます。

## gallery との違い

| | gallery | analytics |
| --- | --- | --- |
| 1 つの画面に | タブごとにチャート 1 つ | 1 つのボードにパネル複数(最大 9 個) |
| データ | 1 つのタブにデータ 1 つ | パネルごとにデータ・チャート・フィルターが別々 |
| チャート 1 枚 | split by の組み合わせごとに item を grid に並べる | 1 つのパネルがチャート 1 枚(split by・grid なし) |
| 描画中 | タブを切り替えられない | 別のパネルを選んで設定を変え、draw してもよい |
| 残る場所 | draw のたびに history に記録 | ボードを自動保存。history には残らない |

## 画面構成

```
┌ トップバー: upload · datastore · gallery · history · analytics · shares · feed · help ┐
├ ツールバー: [パネル追加][レイアウト][ボードを空にする][draw all] │ モードバー │ チャートツール   リンクをコピー · フィードに投稿 · フィルター ┤
├ 左パネル ─────────┬ ボード ─────────────────────────────────┬ フィルタードロワー ┤
│ パネル2 · Bar      │ ┌ パネル1 ───┐┃┌ パネル2 ──────────┐   │                    │
│ データ             │ │   PNG      │┃│   PNG             │   │                    │
│ チャート・カラム   │ └────────────┘┃└───────────────────┘   │                    │
│ 全体設定           │ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━   │                    │
│ draw               │ ┌ パネル3 ───────────────────────────┐   │                    │
│                    │ └────────────────────────────────────┘   │                    │
│                    ├ ボトムバー: パネル数 · 描画中 · 失敗 · Worker · 選択中パネルの進行 ┤
└────────────────────┴──────────────────────────────────────────┴────────────────────┘
```

- **左パネル** は選択中のパネル(枠が強調されたパネル)の設定です。上部にパネル番号とチャート名が表示されます。gallery の左パネルから grid と split by を除いた形です。
- パネルをクリックするか、パネル内にフォーカスが入るとそのパネルが選択されます。
- パネルの左上にカーソルを合わせると、パネル枠のツール(移動ハンドル、ラベル(番号 · チャート · データ)、連動ボタン、最大化、削除)が表示されます。

## パネルの追加と削除

- **パネル追加** で空のパネルを追加します。新しいパネルは選択中のパネルのデータで始まり、チャートは Scatter です。
- パネルは 9 個まで置けます。9 個になると **パネル追加** が薄くなり、カーソルを合わせると理由が表示されます。
- パネル枠の X でパネルを削除します。描いたチャートがあるパネルは確認を求めます。最後の 1 つのパネルは削除できません。
- パネル番号はボードの左上から読んだ順です。パネルを移動すると番号が変わります。
- **ボードを空にする** は、確認のあとすべてのパネルと描いたチャートを削除し、空のパネル 1 つに戻します。描画中のパネルはキャンセルします。

## レイアウト

**レイアウト** を押すと、パネル数ごとの配置 17 種類を小さな図から選べます。いまの配置と同じ図は押された状態で表示されます。

| パネル数 | 配置 |
| --- | --- |
| 1 | 1×1 |
| 2 | 1×2, 2×1 |
| 3 | 1×3, 3×1, 左・右・上・下に大きいパネル 1 つ + 小さいパネル 2 つ |
| 4 | 2×2, 1×4, 4×1, 左に大 + 右に 3 つ, 上に大 + 下に 3 つ |
| 6 | 2×3, 3×2 |
| 9 | 3×3 |

R×C は行×列です(1×2 は 1 行に 2 つ)。パネルが足りなければ空のパネルを追加し、余れば番号の大きいパネルから削除します。描いたパネルが削除される場合は先に確認を求めます。

## ドラッグして移動

パネル枠のハンドル(⠿)をドラッグして別のパネルの上に置きます。置く位置は、そのパネルでポインターに最も近い辺(上・下・左・右)です。ドラッグ中は置く辺が塗られ、変わったあとの配置と新しい番号が輪郭で表示されます。

キーボードでも移動できます。

1. ハンドルにフォーカスを置き、<Kbd>Space</Kbd> か <Kbd>Enter</Kbd> でつかみます。
2. 矢印キーで置くパネルと辺を選びます。最初はその方向で最も近いパネルに移って向かい合う辺を選び、そのパネル内では押した方向の辺を選び、すでにその辺なら次のパネルに移ります。
3. <Kbd>Space</Kbd> か <Kbd>Enter</Kbd> で置きます。<Kbd>Esc</Kbd> でキャンセルします。

## 大きさの調整

パネルの間の境界をドラッグして大きさを変えます。ドラッグ中はパネルの位置だけが変わり、離すと大きさが変わったパネルだけをその大きさで 1 回描き直します。境界にフォーカスを置き、矢印キーで 2% ずつ、<Kbd>Home</Kbd>・<Kbd>End</Kbd> で端まで動かすこともできます。パネル 1 つは 5% より小さくなりません。

## 最大化

パネル枠の最大化ボタンを押すか、パネルをダブルクリックすると、そのパネルだけがボード全体に表示されます。同じボタンか <Kbd>Esc</Kbd> で戻ります。別のパネルを選んだり、レイアウトを変えたりしても解除されます。最大化している間、ほかのパネルは大きさを保ったまま隠れるだけなので、描き直しません。

## パネルごとのデータ・チャート・フィルター

- 左パネルで変えた値はそのパネルにだけ残ります。別のパネルを選んで戻っても、編集中の値はそのままです。
- データを変えると、そのデータにないカラムは gallery と同じく既定値に直します。
- **フィルター** は選択中のパネルのフィルタードロワーを開きます。フィルターはそのパネルを draw したときに適用されます。→ [フィルター](/help/vis/filter)
- **全体設定** と item 属性(⚙)もそのパネルにだけ適用されます。→ [装飾](/help/vis/customize)

## draw と draw all

- **draw** は選択中のパネルだけを描きます。
- **draw all** は設定が終わったすべてのパネルを番号順に描きます。x・y を選んでいないパネルや描画中のパネルはスキップし、いくつスキップしたかを知らせます。
- 描画中のパネルが 1 つでもあると **draw all** は **cancel all** に変わり、押すとすべてのパネルの描画をキャンセルします。
- パネルごとに別々に描くので、描画中でもほかのパネルを選び、設定を変えて draw できます。
- ボトムバーの左にはパネル数、描画中のパネル数、失敗したパネル数、Render Worker 数が、右には選択中のパネルの進行が表示されます。

### 描画中のロック

描画中のパネルがある間(パネルの大きさに合わせた描き直しを含む)は、パネルの追加・削除、移動、大きさの調整、レイアウトの変更ができません。ボタンにカーソルを合わせると理由が表示されます。描き終わるか **cancel all** でキャンセルすると解除されます。**ボードを空にする** は描画中でも使えます。

## ボード全体にかかるツール

- **モードバー** はボードに 1 つです。選んだモードはすべてのパネルに適用され、そのパネルのチャートが対応していないモードなら、そのパネルだけ基本モードのままにします。→ [チャートを調べる](/help/vis/explore)
- **チャートツール**(ダウンロード、データテーブルなど)、**リンクをコピー**、**フィードに投稿** は選択中のパネルのチャートが対象です。すべてのチャートの Excel ダウンロードはありません。
- パネル内の操作(ツールチップ、移動・拡大、図形、選択、削除、ペイント、legend、右クリックメニュー)は gallery の item と同じです。

## パネル連動

あるパネルで選んだ領域に、別のパネルを連動させます。たとえば scatter パネルで期間を選択すると、それに連動する bar パネルがその期間の行だけで描き直されます。

### 連動元を選ぶ

- パネル枠の連動ボタン(鎖のアイコン)か、左パネル下部の **連動元** を押すと連動ウィンドウが開きます。どちらも同じウィンドウです。
- 一覧から、このパネルが連動するパネルを 1 つ選びます。自分自身は選べません。1 つのパネルに複数のパネルが連動できます。
- 連動元にできるのは、選択した領域を行に変換できるチャートです: Scatter、Line(分布サブチャートを除く)、Bar、Boxplot、Histogram、Waterfall。ほかのチャートは一覧で薄く表示され、理由が書かれています。
- **連動を解除** で連動を外します。かかっていた範囲も解除され、元の図で描き直します。

### 絞り込みと強調

| 方式 | 描き方 | 使えるチャート |
| --- | --- | --- |
| 絞り込み | 範囲内の行だけで描きます。軸・集計・legend の値もその行が基準です | すべてのチャート |
| 強調 | すべての行を描き、範囲外の点を薄くします。軸はそのままです | Scatter、Line(分布サブチャートを除く) |

- 最初は、強調を使えるチャートなら強調、そうでなければ絞り込みで始まります。チャートを変えて強調を使えなくなると絞り込みに変わります。
- 薄さは **形状 › 選択外の濃さ** に従います。
- 範囲がかかると、PNG のタイトル行右側の要約の先頭に `연결 1,204행`(絞り込み)または `연결 강조 1,204행`(強調)が付きます。PNG に描く要約の文字は常に韓国語です。行数は、このパネルのデータのうち範囲に合う行数(このパネルのフィルター前)です。

### データが異なるパネル同士

- 2 つのパネルのデータが同じなら、選択された行にそのまま連動します。
- データが異なる場合は **連動列** の組(連動元の列、このパネルの列)を選びます。このパネルは、連動元で選択された行の値と同じ値を持つ行に連動します。
- 既定値は、両方のデータにある名前と型が同じカテゴリ列のうち最初の列です。サンプル同士(IoT センサー 10 万行 ↔ 50 万行)は工場(`factory`)が既定で、設備単位で見るには設備(`machine`)に変えます。合う列がなければ、選ぶまで範囲はかかりません。
- どちらかのデータを変えると、連動列を既定値に戻します。

### 表示

- ラベルの連動ボタンに `← 1`(パネル 1 に連動)、`→ 2, 3`(パネル 2・3 がこのパネルに連動)が表示されます。範囲がかかっているとボタンが強調色になり、カーソルを合わせると `絞り込み 1,204行` のような要約とともに相手のパネルの枠が強調されます。
- 左パネルの **連動元** の右側にも、かかっている範囲が表示されます。
- 範囲をかけられないときはボタンが警告色になり、理由が表示されます。連動ウィンドウの状態行にも理由(連動元が描かれていない、連動列を選んでいない など)が書かれます。

### 範囲が変わるとき

- 連動元で領域を選択したり、削除したり、legend のチェックを変えたりすると、連動するパネルが描き直されます。連動元の拡大・移動や、色・図形の変更では範囲は変わりません。
- 範囲は選択した瞬間の行で決まります。**選択を解除するか、連動元を新しく draw すると**(新しく描くと選択は消えます)範囲も解除されます。連動元の描画に失敗すると範囲が解除され、理由が表示されます。
- 連動は 1 段階だけです。パネル 3 がパネル 2 に、パネル 2 がパネル 1 に連動しているとき、パネル 1 の選択はパネル 2 だけを変えます。パネル 3 はパネル 2 で直接選択した領域だけに連動します。そのため 2 つのパネルが互いに連動しても構いません。
- 連動するパネルが描画中なら、終わったあと最後の選択で 1 回だけ描き直します。描き直している間は前の図の上に進行状況が表示され、レイアウトは変えられません。
- 連動元のパネルを削除すると連動が外れます。

### データテーブルと共有

- 絞り込みのとき、データテーブル・全データテーブル・データダウンロードは範囲内の行だけを含みます。強調のときは描いた行すべてです。
- **リンクをコピー**・**フィードに投稿** の図はパネルに表示されていたまま(要約の文字を含む)ですが、共有したチャートには連動範囲が含まれません。共有ページやパネルの右クリックの **galleryで開く** で開くと、範囲のないチャートとして描きます。

## 自動保存と開き直し

ボードはユーザーごとに 1 つで、変わるたびに自動で保存されます(最後の変更から 1 秒後)。自分で保存する必要はありません。

- 保存するもの: 配置、選択中のパネル、パネルごとに編集中の設定、最後に描いた設定とそのチャートの状態(拡大、図形、選択、削除した領域、個別の色、管理線など)、パネル連動(連動元、方式、連動列)。
- 再読み込みしたり再度ログインしたりして analytics を開くと、保存したボードを読み込み、描いたことのあるパネルを番号順に描き直します。パネル連動がある場合は、連動元を先に描いて選択を戻し、描き終えてから連動するパネルを範囲付きで描きます。
- gallery や history に移動して戻ってもボードはそのまま残り、読み込み直しません。描画中だったパネルも続けて描きます。
- パネルが使っていた自分でアップロードしたデータを削除した場合、そのパネルは理由とともに失敗として開きます。別のデータを選んで draw し直してください。

<Callout>
  ボードもデータ・history と同じく、いま使っているブラウザにのみ保存されます。→ [知っておくこと](/help/vis/faq)
</Callout>

## ほかの画面との行き来

- **datastore → analytics で開く**: 選んだデータを、まだ描いたことのない空のパネルに入れ、空のパネルがなければ新しいパネルを追加して analytics に移動します。9 個すべて埋まっている場合は、選択中のパネルのデータを置き換えるか確認します。→ [データの準備](/help/vis/data#ja-datastore)
- **パネルを右クリック → gallery で開く**: そのパネルが描いた設定で新しい gallery タブを開いて描きます。拡大・図形・色などのチャートの状態は持っていきません。
- analytics で描いたチャートは **history に残りません。** ボードの自動保存がその役割を担います。

## 狭い画面

- 幅が 64rem より狭いと左パネルが折りたたまれます。ツールバー先頭の **パネル設定** で開きます。
- 48rem より狭いと、パネルを番号順に 1 列に積み(4:3)、縦にスクロールします。移動・大きさの調整・レイアウト・最大化は隠れ、パネルの追加・削除だけが残ります。保存した配置はそのままなので、広い画面で再び表示されます。
