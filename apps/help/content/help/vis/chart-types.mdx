## 차트별 설명

### Scatter

x와 y 값마다 점을 찍습니다. 점이 아무리 많아도 PNG로 그리므로 화면이 느려지지 않습니다. legend를 고르면 점을 legend 값별로 칠합니다.

### Line

scatter와 같은 데이터를 x 순으로 이어 그립니다. legend 값마다 선이 하나씩 생깁니다. 서브 차트로 **ECDF·NCDF·Probability**를 고르면 y 값의 분포를 그리며, 이때는 x를 쓰지 않습니다.

### Bar

x 범주마다 y를 통계 함수로 모은 막대를 그립니다. legend를 고르면 범주 안에 legend 값별 막대를 놓습니다. 서브 차트로 나란히(**Side**), 쌓기(**Stack**), 100% 쌓기(**Stack 100**)를 고릅니다.

### Boxplot

x 범주마다 y 값의 분포를 사분위수 상자와 수염(1.5 IQR), 이상치로 보여 줍니다. 서브 차트 **Dot**은 점을 함께 찍습니다.

### Histogram

숫자 컬럼 하나의 분포입니다. 세로축은 개수이고, 구간 폭은 데이터 범위에 맞춰 자동으로 정합니다. 모든 item이 같은 구간을 씁니다.

### Heatmap

x × y 칸마다 z 값을 통계 함수로 모아 색의 진하기로 보여 줍니다.

### Treemap

x 범주마다 y를 모은 값을 넓이로 보여 줍니다.

### Pie

x 범주가 조각, y를 모은 값이 조각 크기입니다. 큰 순으로 8개까지 이름을 붙이고 나머지는 '기타'로 묶습니다. 서브 차트로 **Doughnut·Pie 3D·Sunburst**를 고릅니다. Sunburst는 legend가 바깥 고리가 됩니다.

### Radar

x 범주가 축(3개 이상, 12개까지), y를 모은 값이 축 위의 거리입니다. legend 값마다 다각형이 하나씩 생깁니다.

### Waterfall

x 범주 순서대로 y 값을 누적해, 막대마다 오르내린 만큼을 그리고 마지막에 합계 막대를 둡니다.

### Funnel

x 범주(단계)를 값이 큰 순으로 위에서 아래로 놓고, 이전 단계 대비 전환율과 첫 단계 대비 비율을 적습니다. 8단계가 넘으면 7개와 '기타'로 묶습니다.

### Sankey

출발 범주(x)에서 도착 범주(y)로 가는 흐름을 z 값의 굵기로 그립니다. 출발 노드는 큰 순 7개, 도착 노드는 11개까지 보이고 나머지는 '기타'로 묶습니다.

### Candle

시계열 x를 자동으로 나눈 시간 구간마다 y의 시가·고가·저가·종가를 그립니다. legend는 상승·하락 두 가지입니다.

### Gantt

y의 작업 행마다 시간 막대를 그립니다. legend(예: 상태)를 고르면 같은 값이 이어지는 구간마다 막대를 나눕니다.

## 차트마다 쓸 수 있는 도구

탭 도구 줄의 모드와 체크박스 표시는 차트 종류에 따라 쓸 수 없는 것이 있습니다. 쓸 수 없는 버튼은 흐리게 보이고, 커서를 올리면 이유가 나옵니다.

| 차트 | 이동·확대 | 선택 | 점 삭제 | 페인트 | 체크박스 표시 |
| --- | --- | --- | --- | --- | --- |
| Scatter, Line | O | O | O | O | O |
| Bar, Boxplot, Histogram, Waterfall | O | O | | O | O |
| Heatmap | O | O | | O | |
| Treemap | O | O | | | O |
| Candle, Gantt | O | O | | O | O |
| Pie, Radar, Funnel, Sankey | | O | | | O |

각 도구는 [차트 살펴보기](/help/vis/explore)에서 설명합니다.
