Every draw leaves an entry in history. In history you can revisit charts you drew before and keep editing them.

## What is kept

- Each draw creates one entry.
- Zooms, shapes, item colors and grid changes made afterwards are added to the same entry. Window resizes are not kept.
- The data, chart settings, filters, Settings and item settings, shapes, zoom state, final state of each item (including canceled) and a thumbnail are saved.

Entries are stored only in the browser you are using now.

## Revisiting

1. Press **history** in the top bar.
2. Pick an entry in the list on the left to redraw that chart and open it in a tab. If the entry is already open, you go to that tab.

The revisit screen is view only. Settings can't be changed, only the default (tooltip) mode is available, and item tools are hidden. Revisiting doesn't add a new history entry.

## Continue editing

Press **Edit in gallery** in a revisit tab to bring that chart into a new gallery tab. Later changes continue the original entry.

## Deleting entries

Press the X button at the top right of a list card (shown on hover) and confirm in the popup. A history tab showing that entry is closed too.

<Callout>
  If the sample data an entry used was deleted, it is rebuilt when you revisit. If you deleted data you uploaded yourself, that entry can't be revisited.
</Callout>
