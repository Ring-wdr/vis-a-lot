analytics는 여러 차트를 한 화면에 칸으로 나눠 함께 보는 화면입니다. 상단 바의 **analytics**나 시작 화면의 **여러 차트 함께 보기** 카드로 엽니다.

## gallery와 무엇이 다른가요

| | gallery | analytics |
| --- | --- | --- |
| 한 화면에 | 탭마다 차트 하나 | 보드 하나에 칸 여러 개(최대 9칸) |
| 데이터 | 탭 하나에 데이터 하나 | 칸마다 데이터·차트·필터가 따로 |
| 차트 한 장 | split by 조합마다 item을 grid로 늘어놓음 | 칸 하나가 차트 한 장 (split by·grid 없음) |
| 그리는 동안 | 탭을 바꿀 수 없음 | 다른 칸을 고르고 설정을 고치고 draw해도 됨 |
| 남는 곳 | draw마다 history에 기록 | 보드를 자동 저장. history에는 남지 않음 |

## 화면 구성

```
┌ 상단 바: upload · datastore · gallery · history · analytics · shares · feed · help ┐
├ 도구 줄: [칸 추가][레이아웃][보드 비우기][draw all] │ 모드 바 │ 차트 도구   링크 복사 · 피드에 올리기 · 필터 ┤
├ 왼쪽 패널 ──┬ 보드 ───────────────────────────────────┬ 필터 서랍 ┤
│ 칸 2 · Bar  │ ┌ 칸 1 ──────┐┃┌ 칸 2 ─────────────┐   │           │
│ 데이터       │ │   PNG      │┃│   PNG             │   │           │
│ 차트 · 컬럼  │ └────────────┘┃└───────────────────┘   │           │
│ 전체 설정    │ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━   │           │
│ draw        │ ┌ 칸 3 ──────────────────────────────┐   │           │
│             │ └────────────────────────────────────┘   │           │
│             ├ 하단 줄: 칸 수 · 그리는 중 · 실패 · Worker · 고른 칸의 진행 ┤
└─────────────┴──────────────────────────────────────────┴───────────┘
```

- **왼쪽 패널**은 고른 칸(테두리가 강조된 칸)의 설정입니다. 맨 위에 칸 번호와 차트 이름이 보입니다. gallery의 왼쪽 패널에서 grid와 split by를 뺀 모양입니다.
- 칸을 누르거나 칸 안에 포커스가 들어오면 그 칸을 고릅니다.
- 칸 왼쪽 위에 커서를 올리면 칸 틀 도구가 보입니다: 옮기기 손잡이, 이름표(번호 · 차트 · 데이터), 연결 버튼, 최대화, 지우기.

## 칸 더하고 지우기

- **칸 추가**로 빈 칸을 더합니다. 새 칸은 고른 칸의 데이터로 시작하고 차트는 Scatter입니다.
- 칸은 9개까지 둘 수 있습니다. 9칸이면 **칸 추가**가 흐려지고, 커서를 올리면 이유가 보입니다.
- 칸 틀의 X로 칸을 지웁니다. 그린 차트가 있는 칸이면 확인을 받습니다. 마지막 한 칸은 지울 수 없습니다.
- 칸 번호는 보드 왼쪽 위부터 읽은 순서입니다. 칸을 옮기면 번호가 바뀝니다.
- **보드 비우기**는 확인 뒤 모든 칸과 그린 차트를 지우고 빈 칸 하나로 되돌립니다. 그리는 중인 칸은 취소합니다.

## 레이아웃

**레이아웃**을 누르면 칸 수별로 배치 17가지를 작은 그림으로 고릅니다. 지금 배치와 같은 그림은 눌린 모양입니다.

| 칸 수 | 배치 |
| --- | --- |
| 1 | 1×1 |
| 2 | 1×2, 2×1 |
| 3 | 1×3, 3×1, 왼쪽·오른쪽·위·아래에 큰 칸 하나 + 작은 칸 둘 |
| 4 | 2×2, 1×4, 4×1, 왼쪽 큰 칸 + 오른쪽 3칸, 위 큰 칸 + 아래 3칸 |
| 6 | 2×3, 3×2 |
| 9 | 3×3 |

R×C는 행×열입니다(1×2는 한 줄에 두 칸). 칸이 모자라면 빈 칸을 더하고, 남으면 뒤 번호 칸부터 지웁니다. 그린 칸이 지워지면 먼저 확인을 받습니다.

## 끌어서 옮기기

칸 틀의 손잡이(⠿)를 끌어 다른 칸 위에 놓습니다. 놓을 자리는 그 칸에서 포인터와 가장 가까운 변(위·아래·왼쪽·오른쪽)입니다. 끄는 동안 놓을 변이 칠해지고, 바뀔 배치와 새 번호가 윤곽으로 보입니다.

키보드로도 옮깁니다.

1. 손잡이에 포커스를 두고 <Kbd>Space</Kbd>나 <Kbd>Enter</Kbd>로 집습니다.
2. 화살표 키로 놓을 칸과 변을 고릅니다. 처음에는 그 방향의 가장 가까운 칸으로 가 마주 보는 변을 고르고, 그 칸 안에서는 누른 방향의 변을 고르며, 이미 그 변이면 다음 칸으로 넘어갑니다.
3. <Kbd>Space</Kbd>나 <Kbd>Enter</Kbd>로 놓습니다. <Kbd>Esc</Kbd>는 취소입니다.

## 크기 조절

칸 사이 경계를 끌어 크기를 바꿉니다. 끄는 동안에는 칸 자리만 바뀌고, 놓으면 크기가 달라진 칸만 그 크기로 한 번 다시 그립니다. 경계에 포커스를 두고 화살표 키로 2%씩, <Kbd>Home</Kbd>·<Kbd>End</Kbd>로 끝까지 옮길 수도 있습니다. 칸 하나는 5%보다 작아지지 않습니다.

## 최대화

칸 틀의 최대화 버튼을 누르거나 칸을 더블 클릭하면 그 칸만 보드 전체에 보입니다. 같은 버튼이나 <Kbd>Esc</Kbd>로 돌아옵니다. 다른 칸을 고르거나 레이아웃을 바꿔도 풀립니다. 최대화한 동안 다른 칸은 크기를 그대로 둔 채 감추므로 다시 그리지 않습니다.

## 칸마다 데이터·차트·필터

- 왼쪽 패널에서 고친 값은 그 칸에만 남습니다. 다른 칸을 골랐다가 돌아와도 고치던 값이 그대로입니다.
- 데이터를 바꾸면 그 데이터에 없는 컬럼은 gallery처럼 기본값으로 바로잡습니다.
- **필터**는 고른 칸의 필터 서랍을 엽니다. 필터는 그 칸을 draw할 때 적용됩니다. → [필터](/help/vis/filter)
- **전체 설정**과 item 속성(⚙)도 그 칸에만 적용됩니다. → [꾸미기](/help/vis/customize)

## draw와 draw all

- **draw**는 고른 칸만 그립니다.
- **draw all**은 설정이 끝난 모든 칸을 번호 순으로 그립니다. x·y를 고르지 않았거나 이미 그리는 칸은 건너뛰고 몇 칸을 건너뛰었는지 알립니다.
- 그리는 칸이 하나라도 있으면 **draw all**이 **cancel all**로 바뀌어, 누르면 모든 칸의 그리기를 취소합니다.
- 칸마다 따로 그리므로 그리는 동안에도 다른 칸을 고르고 설정을 고치고 draw할 수 있습니다.
- 하단 줄 왼쪽에 칸 수, 그리는 중인 칸 수, 실패한 칸 수, Render Worker 수가, 오른쪽에 고른 칸의 진행이 보입니다.

### 그리는 중 잠금

그리는 칸이 있는 동안(칸 크기에 맞춰 다시 그리는 중 포함)에는 칸 추가·지우기, 옮기기, 크기 조절, 레이아웃을 막습니다. 버튼에 커서를 올리면 이유가 보입니다. 다 그려지거나 **cancel all**로 취소하면 풀립니다. **보드 비우기**는 그리는 중에도 쓸 수 있습니다.

## 보드 전체에 걸리는 도구

- **모드 바**는 보드 전체에 하나입니다. 고른 모드는 모든 칸에 적용되고, 그 칸의 차트가 지원하지 않는 모드면 그 칸만 기본 모드로 둡니다. → [차트 살펴보기](/help/vis/explore)
- **차트 도구**(다운로드, 데이터 테이블 등), **링크 복사**, **피드에 올리기**는 고른 칸의 차트가 대상입니다. 모든 차트 엑셀 다운로드는 없습니다.
- 칸 안의 조작(툴팁, 이동·확대, 도형, 선택, 삭제, 페인트, legend, 우클릭 메뉴)은 gallery item과 같습니다.

## 칸 연결

한 칸에서 고른 영역을 다른 칸이 따라 보게 잇습니다. 예를 들어 scatter 칸에서 기간을 선택하면, 그 칸을 따르는 bar 칸이 그 기간의 행만으로 다시 그려집니다.

### 따를 칸 고르기

- 칸 틀의 연결 버튼(사슬 아이콘)이나 왼쪽 패널 맨 아래의 **따를 칸**을 누르면 연결 창이 열립니다. 둘은 같은 창입니다.
- 목록에서 이 칸이 따를 칸을 하나 고릅니다. 자기 자신은 고를 수 없고, 한 칸을 여러 칸이 따를 수 있습니다.
- 따를 칸이 될 수 있는 차트는 선택한 영역을 행으로 바꿀 수 있는 차트입니다: Scatter, Line(분포 서브 차트 제외), Bar, Boxplot, Histogram, Waterfall. 다른 차트는 목록에서 흐리게 보이고 이유가 적혀 있습니다.
- **연결 풀기**로 연결을 풉니다. 걸려 있던 범위도 풀려 원래 그림으로 다시 그립니다.

### 거르기와 강조

| 방식 | 그림 | 쓸 수 있는 차트 |
| --- | --- | --- |
| 거르기 | 범위 안의 행만으로 그립니다. 축·집계·legend 값도 그 행 기준입니다 | 모든 차트 |
| 강조 | 모든 행을 그리고 범위 밖 점을 흐리게 합니다. 축은 그대로입니다 | Scatter, Line(분포 서브 차트 제외) |

- 처음에는 강조를 쓸 수 있는 차트면 강조, 아니면 거르기로 시작합니다. 차트를 바꿔 강조를 쓸 수 없게 되면 거르기로 바뀝니다.
- 흐린 정도는 **모양 › 선택 밖 진하기**를 따릅니다.
- 범위가 걸리면 PNG 제목 줄 오른쪽 요약 맨 앞에 `연결 1,204행`(거르기)이나 `연결 강조 1,204행`(강조)이 붙습니다. 행 수는 이 칸 데이터에서 범위에 맞는 행 수(이 칸 필터 전)입니다.

### 데이터가 다른 칸끼리

- 두 칸의 데이터가 같으면 선택된 행을 그대로 따릅니다.
- 데이터가 다르면 **연결 컬럼** 한 쌍(따를 칸 컬럼, 이 칸 컬럼)을 고릅니다. 이 칸은 따를 칸에서 선택된 행의 값과 같은 값을 가진 행을 따릅니다.
- 기본값은 두 데이터에 이름과 타입이 같은 범주 컬럼 중 첫 컬럼입니다. 샘플끼리(IoT 센서 10만 행 ↔ 50만 행)는 공장(`factory`)이 기본이고, 설비 단위로 보려면 설비(`machine`)로 바꿉니다. 맞는 컬럼이 없으면 고를 때까지 범위가 걸리지 않습니다.
- 어느 쪽이든 데이터를 바꾸면 연결 컬럼을 기본값으로 다시 정합니다.

### 표시

- 이름표의 연결 버튼에 `← 1`(칸 1을 따름), `→ 2, 3`(칸 2·3이 이 칸을 따름)이 적힙니다. 범위가 걸려 있으면 버튼이 강조색이고, 커서를 올리면 `거르기 1,204행` 같은 요약과 함께 상대 칸 테두리가 강조됩니다.
- 왼쪽 패널 **따를 칸** 오른쪽에도 걸린 범위가 보입니다.
- 범위를 걸 수 없으면 버튼이 경고색이고 이유가 보입니다. 연결 창의 상태 줄에도 까닭(따를 칸을 그리지 않음, 연결 컬럼을 고르지 않음 등)이 적힙니다.

### 범위가 바뀌는 때

- 따를 칸에서 영역을 선택하거나, 지우거나, legend 체크를 바꾸면 따르는 칸이 다시 그려집니다. 따를 칸을 확대·이동하거나 색·도형을 바꾸는 것은 범위를 바꾸지 않습니다.
- 범위는 선택한 순간의 행으로 정해집니다. **선택을 풀거나 따를 칸을 새로 draw하면**(새로 그리면 선택이 사라집니다) 범위도 풀립니다. 따를 칸을 그리지 못하면(실패) 범위가 풀리고 이유가 보입니다.
- 전파는 한 단계입니다. 칸 3이 칸 2를, 칸 2가 칸 1을 따를 때 칸 1의 선택은 칸 2만 바꿉니다. 칸 3은 칸 2에서 직접 선택한 영역만 따릅니다. 그래서 두 칸이 서로 따라도 됩니다.
- 따르는 칸이 그리는 중이면 끝난 뒤 마지막 선택으로 한 번만 다시 그립니다. 다시 그리는 동안은 이전 그림 위에 진행이 보이고, 레이아웃을 바꿀 수 없습니다.
- 따를 칸을 지우면 연결이 풀립니다.

### 데이터 표와 공유

- 거르기일 때 데이터 테이블·전체 데이터 테이블·데이터 다운로드는 범위 안의 행만 담습니다. 강조일 때는 그린 행 전부입니다.
- **링크 복사**·**피드에 올리기**의 그림은 칸에 보이던 그대로(요약 글자 포함)지만, 공유한 차트에는 연결 범위가 담기지 않습니다. 공유 페이지나 칸 우클릭의 **gallery에서 열기**로 열면 범위 없는 차트로 그립니다.

## 자동 저장과 다시 열기

보드는 사용자마다 하나이고, 바뀔 때마다 자동으로 저장됩니다(마지막 변경 1초 뒤). 따로 저장할 필요가 없습니다.

- 저장하는 것: 배치, 고른 칸, 칸마다 고치던 설정, 마지막으로 그린 설정과 그 차트의 상태(확대, 도형, 선택, 지운 영역, 개별 색, 관리선 등), 칸 연결(따를 칸, 방식, 연결 컬럼).
- 새로고침하거나 다시 로그인해 analytics를 열면 저장한 보드를 받아, 그린 적 있는 칸을 칸 번호 순으로 다시 그립니다. 칸 연결이 있으면 따를 칸을 먼저 그려 선택을 되살리고, 그 칸이 다 그린 뒤 따르는 칸을 범위와 함께 그립니다.
- gallery나 history에 다녀와도 보드는 그대로 남고 다시 받지 않습니다. 그리던 칸도 이어서 그립니다.
- 그 칸이 쓰던 직접 올린 데이터를 지웠다면 그 칸은 사유와 함께 실패로 열립니다. 다른 데이터를 골라 다시 draw하세요.

<Callout>
  보드도 데이터·history처럼 지금 쓰는 브라우저에만 저장됩니다. → [알아 두기](/help/vis/faq)
</Callout>

## 다른 화면과 오가기

- **datastore → analytics에서 열기**: 고른 데이터를 그린 적 없는 빈 칸에 넣고, 빈 칸이 없으면 새 칸을 더해 analytics로 갑니다. 9칸이 모두 차 있으면 고른 칸의 데이터를 바꿀지 묻습니다. → [데이터 준비](/help/vis/data#datastore)
- **칸 우클릭 → gallery에서 열기**: 그 칸이 그린 설정으로 새 gallery 탭을 열어 그립니다. 확대·도형·색 같은 차트 상태는 가져가지 않습니다.
- analytics에서 그린 차트는 **history에 남지 않습니다.** 보드의 자동 저장이 그 역할을 합니다.

## 좁은 화면

- 폭이 64rem보다 좁으면 왼쪽 패널이 접힙니다. 도구 줄 맨 앞의 **설정**으로 엽니다.
- 48rem보다 좁으면 칸을 번호 순으로 한 줄로 쌓아(4:3) 세로로 스크롤합니다. 옮기기·크기 조절·레이아웃·최대화는 숨기고 칸 추가·지우기만 둡니다. 저장한 배치는 그대로라 넓은 화면에서 다시 보입니다.
