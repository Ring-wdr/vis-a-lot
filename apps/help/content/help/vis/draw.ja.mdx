gallery タブの左パネルでデータとカラムを選び、**draw** を押すとチャートを描きます。設定を変えても自動では描き直さないため、変更後は draw を押す必要があります。

## 左パネル

| 項目 | 内容 |
| --- | --- |
| データ | 登録したデータのいずれかを選びます。データを変えると、新しいデータに合わないカラム設定は型に合った既定値に変わります |
| チャート | チャートの種類を選びます。→ [チャートの種類](/help/vis/chart-types) |
| サブチャート | line・bar・boxplot・pie にだけある細かな形です |
| grid | 1 ページに配置する item の行 × 列です |
| x · y · z | チャートに使うカラムです。チャートの種類によって選べるカラムの型が異なります |
| legend | 色分けに使うカテゴリのカラムです。固有値が 8 個以下のカテゴリのカラムだけを選べます |
| 集計関数 | y の値をまとめる方法です: 平均・合計・件数・最小値・最大値・中央値。値をまとめるチャートでのみ表示されます |
| split by | チャートを分けるカラムです。複数選べます |
| tooltip | ツールチップに一緒に表示するカラムです。複数選べます |

## split by と grid

**split by** にカラムを選ぶと、そのカラムの値ごとにチャートを 1 つずつ(item)別々に描きます。複数のカラムを選ぶと、値のすべての組み合わせごとに item ができます。

- 選んだ順番が item 名の順番になります。工場 → シフトの順に選ぶと、item 名は `蔚山-日勤` のようになります。名前をつなぐ文字は全体設定のタイトルメニューで変更します。
- 一覧で項目を押したままドラッグすると、通過した順にまとめて選べます。
- item は最大 **30,000 個** まで描きます。超える場合は draw の前に知らせ、描きません。フィルターをかけている場合は、フィルター適用後の数で数えます。

**grid** は 10 × 10 のマスで行 × 列を選びます(1 × 1 〜 10 × 10)。item が 1 ページより多い場合は複数のページに分かれます。たとえば 3 × 3 の grid に item が 20 個あれば 3 ページです。

<Callout>
  grid のサイズを変えると item のサイズが変わるため、draw を押さなくてもすぐに全体を描き直します。描いている間は grid のサイズを変更できません。
</Callout>

## draw と cancel

draw ボタンは描いている間に状態が変わります。

1. **draw** を押すと、少しの間無効になった状態でリクエストを送ります。
2. 描画が始まるとボタンが **cancel** に変わります。押すと、まだ描けていない item をキャンセルします。
3. 描き終わると再び **draw** になります。

描き終わった item から画面に表示され、その item ではすぐにツールチップや拡大などの操作ができます。描けなかった item にはエラー表示が残ります。

データがまだ読み込み中の場合は、読み込みが終わるまで待ってから描きます。

## ボトムバー

grid の下のボトムバーに進行状況が表示されます。

- 現在の段階と進行率(%)
- 状態ごとの item 数: 完了 · 描画中 · 待機 · 失敗 · キャンセル
- 経過時間、処理速度(item/s)、残り時間の目安

## ページを送る

grid の右側のページスクロールバーでページを送ります。描いている間も送ることができ、ページを送っても描画は止まりません。

- 上・下の矢印: 1 ページずつ(押し続けると連続)
- トラック: 押した方向へ移動
- thumb: ドラッグして移動
- マウスホイール、キーボードの <Kbd>↑</Kbd> <Kbd>↓</Kbd> <Kbd>PageUp</Kbd> <Kbd>PageDown</Kbd> <Kbd>Home</Kbd> <Kbd>End</Kbd>

## ウィンドウのサイズを変えると

ウィンドウのサイズを変えて少し待つと、現在のページの item だけを新しいサイズで描き直します。描き直している間は、前の画像を拡大・縮小して表示します。
