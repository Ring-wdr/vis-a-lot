차트 모양은 모든 item에 함께 적용하는 **전체 설정**과, item 하나에만 적용하는 **item 속성**으로 바꿉니다.

## 전체 설정

왼쪽 패널 아래 **전체 설정**을 누르면 팝업이 열립니다. 왼쪽 메뉴에서 구역을 고르고 값을 바꾼 뒤 **확인**을 누릅니다.

<Callout title="다음 draw에 적용됩니다">
  전체 설정은 바로 다시 그리지 않습니다. 확인을 누른 뒤 draw를 눌러야 그린 차트에 반영됩니다. 바꾼 전체 설정으로 다시 그리면 item마다 따로 정한 속성은 모두 전체 설정 값으로 바뀝니다.
</Callout>

메뉴는 고른 차트 종류가 쓰는 구역만 보입니다.

| 구역 | 바꾸는 것 |
| --- | --- |
| 제목 | 제목·부제목 글자와 색, 정렬, 부제목 글자 크기·정렬, 요약 표시, split item 이름을 잇는 문자 |
| 축 | X축·Y축 보이기, 제목, 최솟값·최댓값, 로그 축, 선·그리드·눈금·눈금 글자, 범주 정렬·순서(X축) |
| 범례 | legend 보이기, 위치(위·아래·왼쪽·오른쪽), 테두리, 정렬·순서, 순서 뒤집기, 글자 |
| 패널 | 배경 색, 그라데이션, 테두리, 여백 |
| 팔레트 | 기본 색, legend 값별 색, 그라데이션 색, 기타 색, 색 목록 |
| 모양 | 점 모양(10가지), 채우기 방식, 투명도, 테두리, 선택 밖 진하기, 막대 모서리 둥글기 |
| 크기 | 점 크기(자동·고정), 글자 크기(자동), 선 굵기 |
| 점 라벨 | 점 옆에 값 적기 (위치, 각도, 앞뒤 글자, 소수 자리) |
| 점수 | 상관계수, 분산분석 F, 규격 내 확률, 공정 능력(Cpk) |
| 예측 | 이동 평균·지수 평활로 다음 값을 예측해 신뢰 구간과 함께 그리기 |
| 값 | 빈 칸 값, 이상치 빼기·이상치만 보기(IQR·정규분포) |
| 강조 | 조건·순위·범위에 맞는 점·막대 강조 |
| 툴팁 | 가장 가까운 점 표시 (화면 표시만 바꿈) |
| 식 | x·y 값을 식으로 바꿔 그리기. 예: `log(y)`, `x * 2 + 1` |

## 순서 바꾸기

legend 항목과 범주 x축의 순서를 직접 정합니다. 범례 구역의 **정렬**·**순서**, 축 › X축의 **범주 정렬**·**범주 순서**에서 바꿉니다.

- **순서** 칸에는 값이 지금 순서대로 늘어서 있습니다. 끌어서 옮기거나, 값에 포커스를 두고 <Kbd>Alt</Kbd>+<Kbd>↑</Kbd> <Kbd>↓</Kbd>로 한 칸씩 옮깁니다. 목록 맨 위부터 마지막으로 옮긴 값까지가 순서로 저장되고(번호가 붙습니다), 나머지 값은 **정렬** 순으로 뒤에 옵니다.
- **정렬**은 **기본 (값 순)** 또는 **자연 정렬**입니다. 자연 정렬은 글자 안 숫자를 수로 비교해 `L1, L2, L10`처럼 놓습니다.
- **처음 순서로**를 누르면 정한 순서를 비웁니다.
- 순서에 있지만 그 item에 없는 값은 건너뜁니다.
- **색은 바뀌지 않습니다.** 색은 지금처럼 값을 따르므로 순서를 바꿔도 같은 값은 같은 색입니다.
- **순서 뒤집기**는 legend 상자의 항목만 뒤집습니다.

| 순서 | 바뀌는 것 | 쓰는 차트 |
| --- | --- | --- |
| legend 순서 | legend 상자의 항목, 범주 안에 나란히 놓는 막대·상자, 쌓는 순서, histogram 구간 안 막대, radar 다각형·line 계열을 그리는 순서 | legend 컬럼을 고르는 차트 (scatter·line·bar·boxplot·histogram·radar·gantt·treemap) |
| 범주 순서 | x축 범주와 그 막대·상자·칸. waterfall은 새 순서대로 누적합니다 | bar·boxplot·waterfall·heatmap(x만) |

고유값이 200개를 넘는 컬럼은 순서를 정할 수 없고 정렬만 고릅니다.

## 강조 방식

강조 구역에서 **방식**을 고르면 그 방식에 맞는 칸만 보입니다. **대상**(x 값·y 값), 색·모양·크기, **나머지는 한 가지 색**은 세 방식이 함께 씁니다.

| 방식 | 강조하는 것 |
| --- | --- |
| 조건 | 연산자(`>` `>=` `<` `<=` `=` `!=`)와 값에 맞는 것 |
| 순위 | 값이 큰 쪽(또는 작은 쪽)부터 정한 개수(1~1,000) |
| 범위 | 최소~최대 사이. 양 끝을 포함하고, 비운 쪽은 끝이 없습니다 |

- 순위는 그 item이 그리는 점·막대·상자 **전체**에서 매기고 확대 범위와 상관없습니다. 체크박스로 끈 legend 값, 지운 점, 뺀 이상치는 빼고 매깁니다. 경계 값과 같은 값은 모두 강조하므로 정한 개수보다 많을 수 있습니다.
- gantt의 y 값은 작업 막대의 길이(시간), candle의 y 값은 종가입니다.

## 점 모양

모양 구역의 **기본 모양**과 강조 구역의 **모양**에서 원·사각형·삼각형·마름모·십자·역삼각형·왼쪽 삼각형·오른쪽 삼각형·육각형·별 10가지를 고릅니다. PNG의 점, legend 표시, 툴팁의 표시가 같은 모양입니다.

## 이상치만 보기

값 구역의 **이상치 가리기**를 켜면 **이상치 처리**를 고를 수 있습니다. 이상치는 **이상치 방식**(IQR 또는 정규분포)과 **k**로 정합니다.

| 차트 | 이상치 빼기 | 이상치만 보기 |
| --- | --- | --- |
| Scatter · Line | y가 범위 밖인 점을 빼고 그립니다. 제목 줄에 뺀 수를 적습니다 | 범위 밖 점만 그립니다. 제목 줄에 '이상치만'을 적습니다 |
| Bar | 범위 밖 막대(모은 값)를 뺍니다 | 범위 밖 막대만 남깁니다 |
| Boxplot | 이상치 점을 빼고 상자만 그립니다 | 상자·수염 없이 이상치 점만 그립니다 |

## 팔레트 색 목록

팔레트 구역의 **색 목록**에 색을 8개까지 더하면 기본 팔레트 8색 대신 legend 값 순서대로 씁니다. 값이 색보다 많으면 처음 색부터 다시 씁니다. **기본 팔레트로**를 누르면 비웁니다.

- legend 값별로 정한 색(item 속성, 전체 설정)이 색 목록보다 먼저입니다.
- **그라데이션 색 쓰기**를 켜면 그라데이션이 색 목록보다 먼저입니다.

## 부제목 크기와 정렬

제목 구역의 **부제목 글자 크기**와 **부제목 정렬**은 비워 두면 제목을 따라갑니다(크기는 제목 크기의 0.9배). 글자 크기는 제목 글자 크기처럼 크기 › 글자 크기 자동을 껐을 때만 씁니다.

## legend 색과 위치

legend는 서버가 PNG 안에 그립니다. 어느 item에서든 같은 값은 같은 색입니다.

- item 위에 커서를 올리고 legend 항목의 **●**를 누르면 색 선택기가 열립니다. 고른 색은 그 item에만 적용됩니다.
- 색은 item 속성 → 전체 설정 → 기본 팔레트 순으로 정해집니다. legend 위치도 같은 순서입니다.

### 체크박스로 값 숨기기

차트 도구의 **체크박스 표시**를 켜면 legend 항목 앞에 체크박스가 나타납니다. 체크를 풀면 그 item에서 그 값의 점·막대 등을 빼고 다시 그립니다. 숨긴 값은 history와 공유에도 남습니다.

## item 개별 속성

item 도구의 **item 속성**(⚙)을 누르면 전체 설정과 같은 구역을 그 item에만 적용하는 팝업이 열립니다. **확인**을 누르면 그 item만 바로 다시 그립니다.

- 범례 구역에서 legend 위치와 legend 값별 색을 바꿉니다. **공통 위치 따르기**·**공통 색 따르기**를 고르면 전체 설정 값을 씁니다.
- 구역마다 **이 구역은 공통 속성 따르기**, 아래의 **모두 공통 속성 따르기**로 전체 설정 값으로 되돌립니다.
- item 속성을 바꾼 구역은 메뉴 이름 뒤에 •가 붙습니다.
- item 속성은 history와 공유에도 남습니다.

## 다크 모드

상단 바의 테마 버튼으로 시스템·라이트·다크를 고릅니다. 차트 PNG도 같은 테마로 다시 그리고, 차트 다운로드도 보고 있는 테마로 받습니다.
