14 種類のチャートを描けます。チャートの種類ごとに x・y・z で選べるカラムの型が決まっていて、合わないカラムは一覧に表示されません。

## 一覧で見る

| チャート | x | y | z | 集計関数 | legend カラム |
| --- | --- | --- | --- | --- | --- |
| Scatter | 数値・日時 | 数値 | | | O |
| Line | 数値・日時 | 数値 | | | O |
| Bar | カテゴリ | 数値 | | O | O |
| Boxplot | カテゴリ | 数値 | | | O |
| Histogram | 数値 | なし | | | O |
| Heatmap | カテゴリ・日時 | カテゴリ | 数値 | O | |
| Treemap | カテゴリ | 数値 | | O | O |
| Pie | カテゴリ | 数値 | | O | |
| Radar | カテゴリ | 数値 | | O | O |
| Waterfall | カテゴリ | 数値 | | O | |
| Funnel | カテゴリ | 数値 | | O | |
| Sankey | カテゴリ (出発) | カテゴリ (到着) | 数値 (フロー値) | O | |
| Candle | 日時 | 数値 | | | |
| Gantt | 日時 | カテゴリ (作業行) | | | O |

legend カラムを選ばないチャートは、チャートが決める値(pie のスライス、funnel の段階、waterfall の増加・減少・合計など)で legend を描きます。

## チャートごとの説明

### Scatter

x と y の値ごとに点を打ちます。点がどれだけ多くても PNG で描くため、画面が重くなりません。legend を選ぶと、点を legend の値ごとに塗り分けます。

### Line

scatter と同じデータを x の順につないで描きます。legend の値ごとに線が 1 本ずつできます。サブチャートで **ECDF・NCDF・Probability** を選ぶと y の値の分布を描き、このときは x を使いません。

### Bar

x のカテゴリごとに、y を集計関数でまとめた棒を描きます。legend を選ぶと、カテゴリの中に legend の値ごとの棒を並べます。サブチャートで横並び(**Side**)、積み上げ(**Stack**)、100% 積み上げ(**Stack 100**)を選びます。

### Boxplot

x のカテゴリごとに、y の値の分布を四分位数の箱とひげ(1.5 IQR)、外れ値で示します。サブチャート **Dot** は点も一緒に打ちます。

### Histogram

数値カラム 1 つの分布です。縦軸は件数で、区間の幅はデータの範囲に合わせて自動的に決まります。すべての item が同じ区間を使います。

### Heatmap

x × y のマスごとに z の値を集計関数でまとめ、色の濃さで示します。

### Treemap

x のカテゴリごとに y をまとめた値を面積で示します。

### Pie

x のカテゴリがスライス、y をまとめた値がスライスの大きさです。大きい順に 8 個まで名前を付け、残りは「その他」にまとめます。サブチャートで **Doughnut・Pie 3D・Sunburst** を選びます。Sunburst では legend が外側のリングになります。

### Radar

x のカテゴリが軸(3 個以上、12 個まで)、y をまとめた値が軸上の距離です。legend の値ごとに多角形が 1 つずつできます。

### Waterfall

x のカテゴリの順に y の値を累積し、棒ごとに上下した分を描いて、最後に合計の棒を置きます。

### Funnel

x のカテゴリ(段階)を値が大きい順に上から下へ並べ、前の段階に対する転換率と、最初の段階に対する比率を記します。8 段階を超える場合は 7 個と「その他」にまとめます。

### Sankey

出発カテゴリ(x)から到着カテゴリ(y)へ向かうフローを、z の値の太さで描きます。出発ノードは大きい順に 7 個、到着ノードは 11 個まで表示し、残りは「その他」にまとめます。

### Candle

日時の x を自動的に分けた時間区間ごとに、y の始値・高値・安値・終値を描きます。legend は上昇・下落の 2 種類です。

### Gantt

y の作業行ごとに時間の棒を描きます。legend(例: 状態)を選ぶと、同じ値が続く区間ごとに棒を分けます。

## チャートごとに使えるツール

タブツールバーのモードとチェックボックス表示には、チャートの種類によって使えないものがあります。使えないボタンは薄く表示され、カーソルを合わせると理由が表示されます。

| チャート | 移動・拡大 | 選択 | 点の削除 | ペイント | チェックボックス表示 |
| --- | --- | --- | --- | --- | --- |
| Scatter, Line | O | O | O | O | O |
| Bar, Boxplot, Histogram, Waterfall | O | O | | O | O |
| Heatmap | O | O | | O | |
| Treemap | O | O | | | O |
| Candle, Gantt | O | O | | O | O |
| Pie, Radar, Funnel, Sankey | | O | | | O |

各ツールは [チャートを調べる](/help/vis/explore) で説明します。
