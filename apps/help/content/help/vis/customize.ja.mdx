チャートの見た目は、すべての item にまとめて適用する **全体設定** と、item 1 つにだけ適用する **item 属性** で変更します。

## 全体設定

左パネル下部の **全体設定** を押すとポップアップが開きます。左側のメニューでセクションを選び、値を変えてから **OK** を押します。

<Callout title="次の draw で適用されます">
  全体設定はすぐには描き直しません。OK を押した後に draw を押すと、描いたチャートに反映されます。変更した全体設定で描き直すと、item ごとに個別に決めた属性はすべて全体設定の値に置き換わります。
</Callout>

メニューには、選んだチャートの種類が使うセクションだけが表示されます。

| セクション | 変更するもの |
| --- | --- |
| タイトル | タイトル・サブタイトルの文字と色、配置、要約の表示、split item 名をつなぐ文字 |
| 軸 | X 軸・Y 軸の表示、タイトル、最小値・最大値、対数軸、線・グリッド・目盛り・目盛りの文字 |
| 凡例 | legend の表示、位置(上・下・左・右)、枠線、順序の反転、文字 |
| パネル | 背景色、グラデーション、枠線、余白 |
| パレット | 基本色、legend の値ごとの色、グラデーションの色、その他の色 |
| 形状 | 点の形、塗りつぶし方法、不透明度、枠線、選択範囲外の濃さ、棒の角の丸み |
| サイズ | 点のサイズ(自動・固定)、文字サイズ(自動)、線の太さ |
| 点ラベル | 点の横に値を表示(位置、角度、前後の文字、小数点以下の桁数) |
| スコア | 相関係数、分散分析の F、規格内確率、工程能力(Cpk) |
| 予測 | 移動平均・指数平滑法で次の値を予測し、信頼区間とともに描く |
| 値 | 空のセルの値、外れ値の除外(IQR・正規分布) |
| 強調 | 条件に合う点・棒の強調 |
| ツールチップ | 最も近い点の表示(画面表示だけを変更) |
| 式 | x・y の値を式で変換して描く。例: `log(y)`、`x * 2 + 1` |

## legend の色と位置

legend はサーバーが PNG の中に描きます。どの item でも、同じ値は同じ色です。

- item の上にカーソルを合わせ、legend 項目の **●** を押すとカラーピッカーが開きます。選んだ色はその item にだけ適用されます。
- 色は item 属性 → 全体設定 → 既定のパレットの順に決まります。legend の位置も同じ順です。

### チェックボックスで値を隠す

チャートツールの **チェックボックス表示** をオンにすると、legend 項目の前にチェックボックスが表示されます。チェックを外すと、その item からその値の点・棒などを除いて描き直します。隠した値は history と共有にも残ります。

## item ごとの属性

item ツールの **item 属性**(⚙)を押すと、全体設定と同じセクションをその item にだけ適用するポップアップが開きます。**OK** を押すと、その item だけをすぐに描き直します。

- 凡例セクションで、legend の位置と legend の値ごとの色を変更します。**共通の位置に従う**・**共通の色に従う** を選ぶと全体設定の値を使います。
- セクションごとの **このセクションは共通属性に従う**、下部の **すべて共通属性に従う** で全体設定の値に戻します。
- item 属性を変更したセクションは、メニュー名の後ろに • が付きます。
- item 属性は history と共有にも残ります。

## ダークモード

トップバーのテーマボタンで、システム・ライト・ダークを選びます。チャートの PNG も同じテーマで描き直し、チャートのダウンロードも表示中のテーマで保存されます。
