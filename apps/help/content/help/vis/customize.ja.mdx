チャートの見た目は、すべての item にまとめて適用する **全体設定** と、item 1 つにだけ適用する **item 属性** で変更します。

## 全体設定

左パネル下部の **全体設定** を押すとポップアップが開きます。左側のメニューでセクションを選び、値を変えてから **OK** を押します。

<Callout title="次の draw で適用されます">
  全体設定はすぐには描き直しません。OK を押した後に draw を押すと、描いたチャートに反映されます。変更した全体設定で描き直すと、item ごとに個別に決めた属性はすべて全体設定の値に置き換わります。
</Callout>

メニューには、選んだチャートの種類が使うセクションだけが表示されます。

| セクション | 変更するもの |
| --- | --- |
| タイトル | タイトル・サブタイトルの文字と色、配置、サブタイトルの文字サイズ・配置、要約の表示、split item 名をつなぐ文字 |
| 軸 | X 軸・Y 軸の表示、タイトル、最小値・最大値、対数軸、線・グリッド・目盛り・目盛りの文字、カテゴリの並べ替え・順序(X 軸) |
| 凡例 | legend の表示、位置(上・下・左・右)、枠線、並べ替え・順序、順序の反転、文字 |
| パネル | 背景色、グラデーション、枠線、余白 |
| パレット | 基本色、legend の値ごとの色、グラデーションの色、その他の色、色リスト |
| 形状 | 点の形(10 種類)、塗りつぶし方法、不透明度、枠線、選択範囲外の濃さ、棒の角の丸み |
| サイズ | 点のサイズ(自動・固定)、文字サイズ(自動)、線の太さ |
| 点ラベル | 点の横に値を表示(位置、角度、前後の文字、小数点以下の桁数) |
| スコア | 相関係数、分散分析の F、規格内確率、工程能力(Cpk) |
| 予測 | 移動平均・指数平滑法で次の値を予測し、信頼区間とともに描く |
| 値 | 空のセルの値、外れ値の除外・外れ値のみ表示(IQR・正規分布) |
| 強調 | 条件・順位・範囲に合う点・棒の強調 |
| 管理線 | 基準線・列の線・帯、規格(USL・LSL)外の強調、規格領域 → [管理線](#ja-管理線) |
| ツールチップ | 最も近い点の表示(画面表示だけを変更) |
| 選択値 | 選択値を作るフィールド(最大 3 つ)と区切り文字。画像には影響しない → [選択値](/help/vis/explore#ja-選択値) |
| 式 | x・y の値を式で変換して描く。例: `log(y)`、`x * 2 + 1` |

## 順序を変える

legend の項目とカテゴリ x 軸の順序を自分で決めます。凡例セクションの **並べ替え**・**順序**、軸 › X軸 の **カテゴリの並べ替え**・**カテゴリの順序** で変更します。

- **順序** 欄には値が今の順に並んでいます。ドラッグで移動するか、値にフォーカスを置いて <Kbd>Alt</Kbd>+<Kbd>↑</Kbd> <Kbd>↓</Kbd> で 1 つずつ移動します。リストの先頭から最後に移動した値までが順序として保存され(番号が付きます)、残りの値は **並べ替え** の順で後ろに続きます。
- **並べ替え** は **既定 (値の順)** または **自然順** です。自然順は文字の中の数字を数として比べ、`L1, L2, L10` のように並べます。
- **元の順序に戻す** を押すと、決めた順序を空にします。
- 順序にあってもその item にない値は飛ばします。
- **色は変わりません。** 色はこれまでどおり値に従うので、順序を変えても同じ値は同じ色です。
- **順序を反転** は legend の枠の項目だけを反転します。

| 順序 | 変わるもの | 使うチャート |
| --- | --- | --- |
| legend の順序 | legend の枠の項目、カテゴリ内に並べる棒・箱、積み上げの順、histogram の区間内の棒、radar の多角形・line の系列を描く順 | legend のカラムを選ぶチャート (scatter・line・bar・boxplot・histogram・radar・gantt・treemap) |
| カテゴリの順序 | x 軸のカテゴリとその棒・箱・セル。waterfall は新しい順序で累積します | bar・boxplot・waterfall・heatmap(x のみ) |

固有値が 200 個を超えるカラムは順序を決められず、並べ替えだけを選びます。

## 強調の方式

強調セクションで **方式** を選ぶと、その方式に合う欄だけが表示されます。**対象**(x 値・y 値)、色・形・サイズ、**残りは単色** は 3 つの方式で共通です。

| 方式 | 強調するもの |
| --- | --- |
| 条件 | 演算子(`>` `>=` `<` `<=` `=` `!=`)と値に合うもの |
| 順位 | 値の大きい方(または小さい方)から決めた件数(1〜1,000) |
| 範囲 | 最小〜最大の間。両端を含み、空にした側は制限がありません |

- 順位はその item が描く点・棒・箱の **全体** で決め、拡大範囲には関係しません。チェックボックスで外した legend の値、削除した点、除いた外れ値は除いて決めます。境界の値と同じ値はすべて強調するため、決めた件数より多くなることがあります。
- gantt の y 値は作業の棒の長さ(時間)、candle の y 値は終値です。

## 管理線

scatter・line・bar の上に、規格の上限・下限、目標値、平均の水準といった基準を線で描き、規格から外れた点・棒を強調します。全体設定と item 属性の **管理線** メニューで設定します。チャートツールの **管理線** ボタンを押すと、全体設定が管理線メニューで開きます(history タブでは表示のみ)。

### 線を追加する

**線の一覧** の下で **追加する線の種類** を選び、**線を追加** を押します。線ごとに名前、軸、色、太さ、線種(実線・破線・点線)を決め、上・下ボタンで順序を変えます。線は 10 本まで、名前は 40 文字までで、同じ名前は使えません。名前は書いたとおりに PNG に描きます。

| 種類 | 項目 | 描く値 |
| --- | --- | --- |
| 基準線 | 値(時系列 x の Bottom 軸なら時刻)、規格 | 入力した値 1 つ |
| 列の線 | 列、関数(平均・最大値・中央値・最小値)、規格、区間ごとの値 | その item の行から集計した値 |
| 帯 | 列 1、列 2、区間ごとの値 | 2 つの列をそれぞれ平均した線 2 本と、その間の塗り |

- 列は数値の列だけを選べ、帯の 2 つの列は別の列にします。
- 列の線・帯の値は、その item の split の組み合わせと draw 時に適用したフィルターの行で集計します。チェックボックスでオフにした legend の値と削除した点も含めるので、チェックボックスを押しても線は動きません。
- 値を求められない線(行がない、すべて空の値)は、その item には描きません。
- 合わない線があると、その線の下に理由が表示され、**OK** を押せません。
- 線の色は決めた色のままで、ダークモードでも変わりません。線と規格外の強調は、チャートのダウンロード・Excel・共有画像にも描きます。

### 使えるチャート

| チャート | Left 軸 (y) | Bottom 軸 (x) |
| --- | --- | --- |
| Scatter, Line | 基準線・列の線・帯 | x が数値なら基準線・列の線・帯、時系列なら基準線 |
| Bar (Side) | 基準線・列の線 | |
| Bar (Stack, Stack 100) | 基準線 | |

- その他のチャートと Line の ECDF・NCDF・Probability には管理線メニューがありません。チャートツールの **管理線** ボタンは、描いたチャートまたは次の draw のチャートが管理線を使わないと薄く表示され、カーソルを合わせると理由が表示されます。
- Bar の列の線は、その item の行全体を集計した 1 本です。積み上げ棒は積み上げた端の値を線と比べ、Stack 100 の値は % です。

### 規格(USL・LSL)と規格外

基準線と列の線の **規格** で USL(上限)か LSL(下限)を選びます。**USL・LSL は軸ごとに 1 つずつ** だけ決められ、帯は規格を選びません。

- **規格外を強調**(既定でオン): Left 軸の規格なら y が、Bottom 軸の規格なら x が USL より大きいか LSL より小さい点・棒を **規格外の色** で塗り直します。USL・LSL と同じ値は規格外ではありません。USL が LSL より小さい場合、その軸は判定しません。
- 規格の線があると、タイトル行に `이탈 N`(規格外の数)を書きます(0 個でも書きます)。拡大範囲に関係なく描いた点・棒全体で数え、チェックボックスでオフにした値と削除した点は数えません。
- Line は間引いて描いた線とは別に、すべての点で判定し、規格外の点を点で描きます。
- 強調セクションと一緒に使うと、強調した点が規格外の点の上に描かれます。選択範囲があっても線は薄くなりません。
- スコアセクションの上限・下限を空にしておくと、規格内確率・Cpk に Left 軸の USL・LSL(区間ごとでないもの)を使います。直接入力した値が優先です。

### 規格領域

**領域を塗る** をオンにすると **塗る側** に従って塗ります。**規格の内側** は LSL と USL の間(片方だけなら、その線からプロットの内側の端まで)、**規格の外側** は USL の上と LSL の下です。**領域の色** と **透明度**(0 不透明 ~ 1 完全に透明、既定 0.8)を決めます。領域と帯の塗りは点の下に敷きます。

### 区間ごとの値(階段線)

scatter・line の Left 軸の列の線と帯で **区間ごとの値(階段線)** をオンにすると、x に沿って変わる規格を階段状に描きます。

- フィルターをかけた全データ(すべての split の組み合わせ)の x の最小~最大を同じ幅の **240 区間** に分け、区間ごとに集計します。そのため、すべての item が同じ区間の境界を使います。
- 値のない区間では線が途切れ、その区間の点は判定しません。x が空の行は区間ごとの集計から外れます。
- 区間は最初に描くときに決まり、拡大しても変わりません。
- 区間ごとの USL・LSL で領域を塗ると区間ごとに塗ります。線の端の文字は右端の区間の値です。

### 時系列 x の基準線

x が時系列なら Bottom 軸には基準線だけを置け、値は **時刻(KST)** 欄に韓国時間で入力します。設備の交換や交代のように、ある時刻を縦線で示すときに使います。線の端の文字の時刻は、軸 › X 軸の日付形式(空なら `年-月-日 時:分`)で書きます。

### 線の名前の文字と軸の範囲

- **線の名前と値を表示**(既定でオン): 線の端に `名前 値` を書きます(帯は `名前 小さい値 ~ 大きい値`)。Left 軸の線は右端の上、Bottom 軸の線は上端の横に置き、他の文字と重なるとずらし、置く場所がなければ書きません。文字色が空なら目盛りの文字色で、文字サイズはサイズ › 文字サイズの自動をオフにしたときだけ使います。サムネイルには文字を書きません。
- **線が見えるよう軸の範囲を広げる**(既定でオン): 拡大していないとき、データの外の線も見えるよう軸の範囲を広げます。軸セクションの最小値・最大値を決めていればその値が優先です。拡大中は拡大した範囲のままなので、範囲外の線と文字は見えません。
- 対数軸では 0 以下の値の線(区間ごとならその区間)を描きません。

### 式を使うとき

式セクションで x・y を変換して描くと、線も変換した座標で描きます。

- 基準線は、変換した軸の目盛りを見て入力した値とみなし、そのまま描きます。
- 列の線・帯の値と区間の境界にはその軸の式を適用します。もう一方の軸の変数を使う式(例: y の式に `x`)なら、列の線・帯は描きません。
- 規格外の判定、ツールチップの値、線の端の文字、スコアの上限・下限はすべて式を適用した値です。

### item 属性と合わなくなった線

- item 属性で線の一覧を決めると、その item は全体設定の一覧の代わりにその一覧を使います。一覧をすべて消すと、その item だけ線がありません。**このセクションは共通属性に従う** で全体設定の一覧に戻ります。
- データセット、チャートの種類・サブチャート、x を変えると、全体設定の中で合わなくなった線を消します。ない列・数値でない列を使う線、その軸で使えない種類(例: Bar Side → Stack での列の線、x が時系列になった Bottom 軸の列の線・数値の基準線)です。区間ごとを使えない Bar に変えると、区間ごとだけをオフにします。名前や USL の重複のように自分で直すものはそのまま残し、理由を表示します。管理線を使わないチャートに変えると、線は残りますが描きません。
- history・共有で復元した item 属性に今のチャートと合わない線があると、その線だけを除いて残りを描きます。

## 点の形

形状セクションの **基本の形** と強調セクションの **形** で、円・四角形・三角形・ひし形・十字・逆三角形・左向き三角形・右向き三角形・六角形・星の 10 種類から選びます。PNG の点、legend の表示、ツールチップの表示が同じ形になります。

## 外れ値のみ表示

値セクションの **外れ値を扱う** をオンにすると **外れ値の処理** を選べます。外れ値は **外れ値の方式**(IQR または正規分布)と **k** で決まります。

| チャート | 外れ値を除く | 外れ値のみ表示 |
| --- | --- | --- |
| Scatter · Line | y が範囲外の点を除いて描きます。タイトル行に除いた数を書きます | 範囲外の点だけを描き、タイトル行にその旨を書きます |
| Bar | 範囲外の棒(集計値)を除きます | 範囲外の棒だけを残します |
| Boxplot | 外れ値の点を除いて箱だけを描きます | 箱・ひげなしで外れ値の点だけを描きます |

## パレットの色リスト

パレットセクションの **色リスト** に色を 8 個まで追加すると、既定パレットの 8 色の代わりに legend の値の順に使います。値が色より多いと最初の色から繰り返します。**既定パレットに戻す** で空にします。

- legend の値ごとに決めた色(item 属性、全体設定)が色リストより優先されます。
- **グラデーションの色を使う** をオンにすると、グラデーションが色リストより優先されます。

## サブタイトルのサイズと配置

タイトルセクションの **サブタイトルの文字サイズ** と **サブタイトルの配置** は、空にしておくとタイトルに合わせます(サイズはタイトルの 0.9 倍)。文字サイズはタイトルの文字サイズと同じく、サイズ › 文字サイズの自動をオフにしたときだけ使います。

## legend の色と位置

legend はサーバーが PNG の中に描きます。どの item でも、同じ値は同じ色です。

- item の上にカーソルを合わせ、legend 項目の **●** を押すとカラーピッカーが開きます。選んだ色はその item にだけ適用されます。
- 色は item 属性 → 全体設定 → 既定のパレットの順に決まります。legend の位置も同じ順です。

### チェックボックスで値を隠す

チャートツールの **チェックボックス表示** をオンにすると、legend 項目の前にチェックボックスが表示されます。チェックを外すと、その item からその値の点・棒などを除いて描き直します。隠した値は history と共有にも残ります。

## item ごとの属性

item ツールの **item 属性**(⚙)を押すと、全体設定と同じセクションをその item にだけ適用するポップアップが開きます。**OK** を押すと、その item だけをすぐに描き直します。

- 凡例セクションで、legend の位置と legend の値ごとの色を変更します。**共通の位置に従う**・**共通の色に従う** を選ぶと全体設定の値を使います。
- セクションごとの **このセクションは共通属性に従う**、下部の **すべて共通属性に従う** で全体設定の値に戻します。
- item 属性を変更したセクションは、メニュー名の後ろに • が付きます。
- item 属性は history と共有にも残ります。

## ダークモード

トップバーのテーマボタンで、システム・ライト・ダークを選びます。チャートの PNG も同じテーマで描き直し、チャートのダウンロードも表示中のテーマで保存されます。
