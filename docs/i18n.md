# 화면 언어 (i18n)

화면은 한국어(`ko`, 기본·원문), 영어(`en`), 일본어(`ja`)로 보인다. 사용자는 상단 바의 사용자 메뉴(작업 화면·공유 페이지) 또는 화면 설정(피드·도움말) 팝오버에서 언어를 고른다. 문구는 [Lingui](https://lingui.dev) 매크로로 쓴다. 라이브러리를 고른 과정은 [i18n-library-comparison.md](./i18n-library-comparison.md)에 있다.

## 구조

| 위치 | 하는 일 |
|---|---|
| `src/shared/config/locale.ts` | 언어 목록, 기본 언어, 저장 키, 첫 페인트 전에 `<html lang>`을 적는 스크립트 |
| `src/shared/lib/i18n.ts` | 고른 언어(localStorage), `useLocale`·`getLocale`·`setLocale`, Intl 헬퍼(`localeCached`, `intlLocale`) |
| `src/shared/lib/lingui.ts` | 언어별 Lingui instance, 카탈로그 등록(`registerCatalog`), `inAllLocales` |
| `src/shared/lib/lingui-provider.tsx` | React context (`application/providers.tsx`가 감싼다) |
| `lingui.config.ts` | 카탈로그 목록. `config/messages.ts`가 있는 slice를 찾아 만든다 |
| `scripts/check-i18n.mjs` | Lingui CLI가 잡지 못하는 것: 자리표시자, 카탈로그 사이 충돌, 등록 import |
| `src/features/switch-locale` | 언어 선택 |

정적 export라 서버가 언어를 알 수 없다. 고른 언어는 localStorage에 두고 테마와 같은 방식으로 읽는다. 정적 HTML(SSR)과 테스트는 기본 언어(`ko`)로 그린다. `setLocale`이 Lingui 전역 instance와 React context를 함께 바꾼다.

## 문구 쓰는 법

원문은 한국어다. 문구는 쓰는 곳에 한국어로 적고, 번역은 slice의 카탈로그(`.po`)에 둔다.

| 쓰는 곳 | 방법 |
|---|---|
| JSX 글자 | `<Trans>로그아웃</Trans>` (`@lingui/react/macro`) |
| 속성·변수 (컴포넌트) | `const { t } = useLingui();` → `` aria-label={t`사용자 메뉴`} `` |
| 복수·선택 | `` t`${plural(n, { other: "#행" })}` ``, `<Plural value={n} other="#행" />` |
| 모듈 위의 표 | `` const STATUS = { open: msg`미해결` } `` → 그릴 때 `i18n._(STATUS.open)` (`useLingui()`의 `i18n`) |
| 컴포넌트 밖 함수 | `@lingui/core/macro`의 `t`·`plural`·`select` (전역 instance, 지금 언어) |
| 서버 컴포넌트·정적 HTML | `` t(linguiFor(lang))`위치` ``, 짧은 글자는 `<StableText {...inAllLocales(msg`피드`)} />` |

- 매크로를 쓰는 파일은 그 slice의 카탈로그 등록 모듈을 import한다: `import "../config/messages";` (application은 `./messages`, shared는 `@/shared/config/messages`). `scripts/check-i18n.mjs`가 검사한다.
- slice에 처음 문구를 두면 `config/messages.ts`를 만든다 (다른 slice의 것을 복사). `lingui.config.ts`가 이 파일로 카탈로그 위치를 찾는다.
- 컴포넌트 밖 `t`로 만든 문구를 그리는 컴포넌트는 `useLocale()`이나 `useLingui()`로 언어 변경을 구독한다. `useMemo`로 문구를 만들면 언어를 의존성에 넣는다.
- 날짜·숫자 포매터는 `localeCached`로 언어마다 하나씩 만든다 (`dateTime().format(at)`). `toLocaleString()`에는 `intlLocale()`을 넘긴다.
- 문장을 조각으로 이어 붙이지 않는다. 언어마다 어순이 달라 문장 전체를 한 메시지로 두고 값은 자리표시자로 넣는다.
- 짧거나 뜻이 갈리는 문구("취소", "보기")는 `msg({ message: "취소", context: "post status" })`로 context를 붙인다. 카탈로그는 slice마다 나눠도 실행 중에는 한 표로 합쳐져, 같은 원문을 다르게 번역하면 한쪽만 남는다 (검사 스크립트가 잡는다).
- 번역가에게 필요한 설명은 `comment`로 남긴다: `msg({ message: "{n}개", comment: "선택한 item 수" })`.

### 조사

`josa()`로 붙이지 않고 받침 종류를 `select` 인자로 넘긴다. 다른 언어 번역은 그 인자를 쓰지 않는다.

```ts
t`상태를 ${from} → ${to}${select(batchim(to), { none: "로", rieul: "로", other: "으로" })} 바꿨습니다`
// en.po: "changed status {from} → {to}"
```

### 작업 순서

1. 코드에 한국어로 매크로를 쓴다.
2. `pnpm lingui:extract`로 `.po`를 고친다.
3. 언어마다 `.po`의 `msgstr`을 채운다 (`en.po`, `ja.po`).
4. `pnpm lingui:check` (추출 누락, 번역 누락, 자리표시자·충돌·등록 검사).

`pnpm build`는 추출 누락(`lingui check sync`), 번역 누락(`lingui compile --strict`), `check-i18n`에서 멈춘다. 컴파일한 `*.ts` 카탈로그는 커밋하지 않는다 (`dev`·`build`·`test`가 만든다).

### 함정

- ICU에서 `'`는 바로 뒤가 `{` `}` `#`일 때 이스케이프다. 작은따옴표로 자리표시자를 감싸려면 `''{item}''`로 적는다 ("Couldn't"는 그대로 써도 된다).
- 원문을 고치면 id가 바뀐다. 추출하면 옛 번역은 버려지니 번역을 다시 채운다.
- production 매크로는 원문을 지우므로 `ko` 카탈로그도 컴파일해 등록한다.
- 일본어 복수형은 `other` 하나다. 따옴표로 감싼 값(`''{title}''`)은 일본어에서 「{title}」로 쓴다.

### 언어 더하기

1. `src/shared/config/locale.ts`의 `LOCALES`·`LOCALE_NAMES`, `src/shared/lib/i18n.ts`의 `INTL_LOCALE`에 넣는다.
2. `app/globals.css`에 `lang-<언어>` 변형을 더하고 `StableText`·`Localized`의 언어별 클래스 표를 채운다 (타입이 빠진 곳을 알려 준다).
3. 각 slice의 `config/messages.ts`(와 `src/application/messages.ts`)가 그 언어 카탈로그를 등록하게 한다.
4. `pnpm lingui:extract`로 `<언어>.po`를 만들고 번역을 채운다. 도움말 본문은 `content/help/<서비스>/<slug>.<언어>.mdx`를 더하고 `views/help-article/config/content.ts`에 적는다.

## 번역하지 않는 것

- 제품 이름 `vis-a-lot`, 그리고 사용자·서버가 정한 데이터(데이터셋·컬럼 이름, 게시물 제목, 사용자 이름, 그룹 이름 등).
- 이미 영어로 적은 화면 이름(upload, datastore, gallery, history, shares, feed, help, draw 등)은 모든 언어에서 같다.
- 코드 주석과 테스트 이름.

## 레이아웃

언어를 바꿔도 상단 바·도구 줄·버튼의 높이와 자리가 바뀌지 않아야 한다.

- 번역은 한국어와 비슷한 길이로 짧게 쓴다. 상단 바·도구 줄·탭·버튼의 문구는 한 줄로 두고(`whitespace-nowrap`, 필요하면 `truncate`), 높이는 정해진 크기(`h-7.5` 등)를 그대로 쓴다.
- 상단 바·탭·배지처럼 옆에 다른 요소가 붙은 짧은 글자는 `StableText`로 그린다. 모든 언어를 한 칸에 겹쳐 가장 긴 폭을 잡아 두므로 언어를 바꿔도 옆 요소가 움직이지 않는다.
- 서버 컴포넌트(도움말)는 `Localized`(긴 글, 본문)나 `StableText`(짧은 글자)로 모든 언어를 함께 그리고 `<html lang>`에 맞는 쪽만 보인다 (`lang-*` 변형).
- 언어 선택·테마 선택처럼 고르는 값에 따라 글자가 바뀌는 곳은 폭을 고정하거나 같은 비율(`flex-1 basis-0`)로 나눈다.
- 사용자 메뉴의 트리거에는 사용자 이름만 둔다 (화면 언어와 상관없는 글자).
