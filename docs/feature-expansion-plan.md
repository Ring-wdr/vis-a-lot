# 기능 확장 기획

> vis-a-lot에 더 넣을 기능 후보를 모으고, 무엇을 어떤 순서로 만들지 정한다.
> 이 문서는 후보와 순서를 다룬다. 고른 기능마다 스펙이 따로 있다.

기준: `develop` 0.18.2.

---

## 1. 지금 있는 것

후보를 고를 때 기준이 되는 현재 범위다. 자세한 동작은 [prototype-spec.md](prototype-spec.md)에 있다.

| 영역 | 지금 |
|---|---|
| 차트 | 14종(scatter, bar, boxplot, line, sankey, heatmap, treemap, candle, gantt, pie, radar, histogram, waterfall, funnel)과 서브 차트 |
| 차트 속성 | 제목, 축, 범례, 패널, 팔레트, 모양, 크기, 점 라벨, 점수, 예측, 값, 강조, 툴팁, 식. 공통 → item 개별 순으로 합친다 |
| 조작 | 확대·이동, 사각형·자유형 선택, 점 삭제, 페인트, legend 체크박스, 즐겨찾기, 새 범례 |
| 보기 | split by × grid 페이지, 크게 보기와 섬네일, 데이터 테이블(item·전체), 필터 |
| 데이터 | IoT 샘플(10만·50만·100만 행), CSV·zip 업로드, datastore |
| 내보내기 | PNG, 엑셀, CSV, 공유 스냅숏, 피드에 올리기 |
| 그 밖 | history, 탭, 다크 모드, 다국어, 도움말, 피드 |

이 구조에서 보이는 빈 곳:

- 화면 하나는 **데이터 하나 × 설정 하나**다. 서로 다른 데이터나 차트를 나란히 놓고 볼 수 없다.
- 제조 데이터인데 **규격·기준을 차트에 표시할 수 없다.** 수준 상승이나 이상 구간을 눈으로만 가늠한다.
- split item이 30,000개까지 생기는데 **이름으로 찾을 길이 없다.** 페이지를 넘겨 찾아야 한다.
- 차트를 **다른 사이트에 넣을 수 없다.** 공유는 같은 브라우저 안의 링크뿐이다.
- 범주·legend의 **순서를 직접 정할 수 없다.** 강조는 조건 하나뿐이다.

## 2. 후보

값(보여 줄 것이 늘어나는 정도)과 비용은 상·중·하로 어림했다.

### 2.1 분석 기능

| # | 후보 | 내용 | 값 | 비용 |
|---|---|---|---|---|
| A1 | **관리선** | 차트 위에 기준선(고정 값), 컬럼 집계선(평균·최소·최대·중앙값), 두 컬럼 사이 띠를 그린다. 상한·하한 규격, 규격을 벗어난 점 강조, 영역 채우기, 선 색·굵기·모양. 서버가 PNG에 그리고 metadata로 위치를 준다 | 상 | 중 |
| A2 | **Analytics** | gallery가 "한 설정 × split grid"라면 analytics는 "칸마다 다른 데이터·차트·필터"다. 칸 추가·삭제, 끌어서 재배치, 경계를 끌어 크기 조절, 레이아웃 preset, 칸 크기가 바뀌면 다시 그리기 | 상 | 상 |
| A3 | **칸 연결** | 한 칸에서 고른 영역을 다른 칸이 따른다. 따르는 칸은 그 행만 남기거나 강조해 다시 그린다. A2가 먼저다 | 상 | 중 |
| A4 | 컬럼 역할 확장 | y 여러 개, 보조 y축, 숫자 컬럼으로 점 크기, 범주 컬럼으로 점 모양 | 중 | 중 |
| A5 | 측정값 묶기 | 숫자 컬럼 여러 개를 측정값 축으로 돌려 item이나 legend로 나눈다. 넓은(wide) 업로드 데이터에 맞다 | 중 | 중 |
| A6 | item 제목 검색 | 이름 조건에 맞는 item만 grid·크게 보기에 남기고 개수를 보인다. 일치 방식을 고르고 조건을 여러 개 쌓는다 | 중 | 하 |
| A7 | 범례 사용자 묶음 | 전체 legend 값 목록에서 값을 골라 이름 붙인 묶음 여러 개로 만든다(나머지는 기타). 지금 '새 범례'는 선택 영역에서만 만든다. 미뤄 둔 sankey·polar "기타" 겹침과 함께 본다 | 중 | 중 |
| A8 | 순서 바꾸기 | legend 값 순서와 범주 x축 순서를 직접 정한다. 지금은 순서 뒤집기만 있다 | 중 | 하 |
| A9 | 강조 확장 | 지금 강조는 조건 하나(x 또는 y, 연산자, 값)다. 순위(위·아래 N개)와 범위를 더한다 | 하 | 하 |
| A10 | 선택 필드 값 묶기 | 고른 점의 지정 컬럼 값을 구분 문자로 이어 복사하거나 밖으로 전달한다. 임베드(C1)의 선택 이벤트와 짝이다 | 하 | 하 |
| A11 | 피벗 표 내려받기 | 행 묶음 컬럼 × 피벗 컬럼 값 × 집계 함수로 표를 만들어 CSV로 받는다 | 중 | 하 |
| A12 | 속성 빈칸 채우기 | 통계 함수(고유 개수, 표준편차, 사분위), 점 모양, 이상치만 그리기, 팔레트 색 목록, 부제목 글자처럼 구역마다 비어 있는 칸 | 하 | 하 |
| A13 | 보조 축으로 옮기기 | 고른 legend 계열을 오른쪽 보조 y축으로 옮긴다. 보조 y축이 없어 렌더러·선택·확대까지 바뀐다 (A4와 겹친다) | 중 | 중 |

## 3. 지금 구조에 넣을 때 걸리는 것

| 후보 | 걸리는 것 |
|---|---|
| A1 관리선 | 저장 위치가 차트 속성 구역인지 별도 필드인지. 공통·item 합치는 순서(전체 → 테마 → 차트 종류 → 공통 → item)에 넣을 수 있어야 한다 |
| A2 Analytics | 작업 상태(`useTabs`, `useWorkspace`)가 탭 단위다. 칸 단위로 쪼개야 한다. DB Worker가 하나라 칸이 많으면 조회가 순서대로 밀린다 |
| A3 칸 연결 | 선택 영역(데이터 좌표)을 다른 차트의 행 조건으로 바꿔야 한다. 데이터셋이 다르면 연결할 컬럼이 필요하다 |
| A4 y 여러 개 | `ChartSpec`의 y가 하나다. history·공유·검증·툴팁·데이터 테이블이 모두 따라 바뀐다 (API 호환 깨짐) |
| D1 SQL | 사용자가 쓴 SQL을 그대로 돌린다. 읽기 전용 + `select`만 + 시간·행 수 한도가 필요하다 |
| C1 임베드 | iframe 안에서 Service Worker(MSW)·PGlite·IndexedDB가 뜬다. 브라우저의 저장소 분할 때문에 끼워 넣은 사이트마다 저장소가 따로다. iframe이 여럿이면 PGlite 여럿이 같은 IndexedDB를 연다. 작은 실험이 먼저다 |
| B2 Wafer map | 차트보다 샘플 데이터(lot·wafer·die 좌표·측정값)가 일이다 |

## 4. 정한 것 (2026-11-17)

| 항목 | 결정 |
|---|---|
| 순서 | 차트 다듬기 → 관리선 → Analytics → 임베드 |
| PR | 기능마다 PR을 develop으로 올린다. 작업 단위는 크게 잡는다 (에이전트 한 명이 큰 덩어리 하나) |
| Analytics의 자리 | gallery의 모드가 아니다. 여러 데이터를 함께 쓰는 별도 서비스로, 자기 경로와 셸을 갖는다 |
| 샘플 데이터 | 현상 유지. IoT 샘플만 쓰고 새 샘플 종류는 만들지 않는다 |
| 원격 push | 사용자 허락을 받고 올린다 |

## 5. 단계와 스펙

| 단계 | 내용 | 후보 | 스펙 |
|---|---|---|---|
| 1 | 차트 다듬기 | A6 제목 검색, A8 순서 바꾸기, A9 강조 확장, A12 속성 빈칸 채우기 | [chart-refinement-spec.md](chart-refinement-spec.md) |
| 2 | 관리선 | A1 | [control-limit-spec.md](control-limit-spec.md) |
| 3 | Analytics | A2 칸 레이아웃, A3 칸 연결. 스펙은 PR 둘(보드 / 연결)을 권한다 | [analytics-spec.md](analytics-spec.md) |
| 4 | 임베드 SDK | C1, A10 선택 필드 값 묶기, Q2 타입 문서. A13 보조 축은 별도 PR을 권한다 | [embed-spec.md](embed-spec.md) |

단계마다 브랜치·작업 단위·완료 기준은 그 스펙에 있다. 앞 단계가 develop에 들어간 뒤 다음 단계를 시작한다. 임베드는 관리선 전달이 2단계에 기대고, 다른 출처 iframe 실험이 첫 작업이다.

이 문서의 후보 설명과 스펙이 다르면 스펙이 맞다.

## 6. 이번 순서에 없는 것

필요해지면 2장의 표에서 다시 꺼낸다.

- 분석: A4 컬럼 역할 확장, A5 측정값 묶기, A7 범례 사용자 묶음, A11 피벗 표 내려받기
- 차트: B1 Contour (IoT 샘플로 그릴 수 있다). B2 Wafer map·B3 지도는 새 샘플이 필요해 '샘플 현상 유지'와 맞지 않는다. B4~B6은 뒤로
- 데이터: D1 SQL 데이터셋, D2 열기 방식, D3 이벤트 데이터셋, D4 주기 적재
- 제품: C3 기본값 관리, C4 즐겨찾기 보관함, C5 운영 화면, C6 계정
- 품질: Q1 e2e 테스트. Analytics·임베드 스펙에서 필요한 만큼만 다룬다
- 하지 않는 것: 작업을 파일·폴더로 저장하는 프로젝트 화면, 3D 차트
